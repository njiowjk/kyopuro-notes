# C - Reindeer and Sleigh 2

## 問題概要

各テストケースで `N` 匹の重さ `W_i` と力 `P_i` を読み、引き手の力の総和で乗り手の重さの総和を支えられる場合の最大乗車数を出力する。ケース全体で `N` の総和は `3×10^5` 以下、各 `W_i` と `P_i` は `1..10^9`。

## 解法の概要

全員が引く状態で使える力は `sum P_i`。個体 `i` を乗せると重さが `W_i` 増え、引く力が `P_i` 減る。したがって費用 `W_i+P_i` の要素を、予算 `sum P_i` 以下で最大何個選べるかに変換できる。

どの `k` 個を選んでも、その費用和は昇順の先頭 `k` 個の和以上になる。費用が正なので、予算内に収まる最長の接頭辞の長さが答え。1ケースで時間 O(N log N)、メモリ O(N)。

主分類は [配列](../../分野/配列/配列.md)。

## 問題固有の実装ポイント

- 乗客がいない状態も可。費用和と予算が等しいときはその1匹を乗せられる。
- C++ では予算と費用の累計に `long long` を使う。

## 自作コード

Python の照合済み実装は、入力のたびに全体の力を足し、各個体の費用を配列に入れる。整列後は、次を選んでも予算内なら費用の累計と選択数を更新する。次の費用は減らないので、初めて予算を超えた時点で走査を打ち切っても同じ結果になる。 本人の提出との対応とジャッジ結果は未確認。

照合済み実装で公式サンプル全1件と、予算と費用が等しいケース、誰も乗れないケース、重さと力が最大のケースを確認した。
