# C - Prepare Another Box

## 解法の概要

`N`、おもちゃ `N` 個と箱 `N-1` 個の大きさを読む。おもちゃ以上の大きさの箱に1個ずつ入れるために買い足す箱の最小サイズを出力する。不可能なら `-1`。`2 <= N <= 2×10^5`、サイズは `1..10^9`。

両方を整列して大きい側から処理する。最も大きいおもちゃが既存の最大箱に入る場合、その組を先に確定できる。実行可能な割り当てで最大箱が小さいおもちゃを受けていた場合でも、大きいおもちゃが使っていた箱に小さい方を移せる。入らない場合は、どの既存箱にも入らないので、追加箱のサイズは少なくともそのおもちゃのサイズになる。同じ状況が二度発生したら不可能で、残りをすべて既存箱に割り当てられたら記録したサイズが最小。

整列込みで時間 O(N log N)。保持する配列と Python の整列時の作業領域は O(N)、整列後の走査の作業領域は O(1)。主分類は [配列](../../分野/配列/配列.md)。

## 問題固有の実装ポイント

- おもちゃと箱の大きさが等しい場合は割り当てられる。割り当てに成功したときだけ既存箱を1個消費する。
- 既存箱が先に尽きて、最後のおもちゃが残る場合は、そのおもちゃの大きさが答え。おもちゃの大きさが常に正なので、追加箱をまだ使っていない状態を0で表せる。

## 自作コード

Inbox で照合した Python のローカルスナップショットを参照した。提出との対応とジャッジ結果は未確認。

整列した両配列の末尾を比較し、既存箱を使ったときは両方の末尾を取り除く。買い足す箱に入れるときは、おもちゃだけを取り除き、必要な大きさを `ans` に残す。二度目の不足で `-1` を出す。

公式サンプル3件、小さい入力での全割り当てとの照合、追加箱が最初と最後に必要な場合、割り当て不能、20万個のおもちゃがすべて同サイズのケースを確認した。
