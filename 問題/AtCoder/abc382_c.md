# C - Kaiten Sushi

## 問題概要

`N` 人が順に並び、各寿司について、しきい値 `A_i` が美味しさ `B_j` 以下の最初の人の番号を求める。該当者がいなければ `-1`。`N, M, A_i, B_j` はすべて `1..2×10^5`。

## 解法の概要

左から見て、それ以前の最小値よりも小さい `A_i` だけを、しきい値と人の番号の表に登録する。すでに同じかより小さい値を持つ人が前にいるなら、後から来た人が最初になる寿司は存在しない。登録されたしきい値間を小さい値から埋めると、各美味しさへの答えを直接引ける。

美味しさの上限を `V` とすると時間 O(N+M+V)、保存済み実装のメモリ O(N+M+V)。

主分類は [配列](../../分野/配列/配列.md)。

## 問題固有の実装ポイント

- 同じしきい値なら番号の小さい人が優先される。更新は厳密に前の最小値を下回ったときだけ。
- 美味しさとしきい値が等しい場合も食べられる。最小しきい値を下回る美味しさの答えは `-1` のまま。

## 自作コード

Python の照合済み実装は、値 `b` に対する答えを添字 `b-1` に持つ。接頭辞最小値が更新された位置だけに人の番号を書き、空欄なら左隣の答えを引き継ぐ。登録された値が高いほど前の人なので、より大きなしきい値の登録位置に達したらそこで答えが切り替わる。 本人の提出との対応とジャッジ結果は未確認。

照合済み実装で公式サンプル全3件と、閾値の重複、該当者なし、値域の両端を確認した。
