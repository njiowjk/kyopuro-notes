# C - Make it Simple

## 問題概要

`N M` と `M` 本の無向辺 `u_i v_i` を読む。全頂点を残して、自己ループも多重辺もない単純グラフにするために必要な最小削除数を出力する。`1 <= N <= 2×10^5`、`0 <= M <= 5×10^5`、端点の番号は1〜`N`。端点順は任意。

## 解法の概要

自己ループは全て除く。異なる2頂点を結ぶ無向辺が `k` 本あれば、1本を残して `k-1` 本を除く必要があり、それで十分。最初の1本を覚え、同じ端点対が再び来るたびに削除数を1増やせば、各組で必要な削除数が集計できる。保存済みコードはハッシュ集合を使うので、期待時間 O(M)、追加メモリ O(M)。

主分類は [グラフ](../../分野/グラフ/グラフ.md)。

## 問題固有の実装ポイント

- `(u,v)` と `(v,u)` は同じ無向辺。両方の順序で探すか、挿入前に小さい番号を先にしてキーを正規化する。
- 自己ループは初出でも削除する。ループの重複を別に数えると二重計上になる。
- 入力の辺が0本なら出力は0。閉路の有無は単純グラフの条件に含まれない。

## 自作コード

Inbox で照合した Python のローカルスナップショット（取得元 `atc-rs-local`）を参照した。提出との対応とジャッジ結果は未確認。

端点を0-indexedに直し、`u == v or (v,u) in edge or (u,v) in edge` なら `ans` を1増やす。その後で入力順のタプルを集合へ追加する。既に削除対象となったタプルも保存するが、自己ループは先頭条件で判定でき、一度見つかった端点の組は以後も既出なので答えは変わらない。C++案では端点を正規化し、有効な辺だけを保持する。

検証では全3サンプルと、辺0本、逆順・同順の重複、自己ループを含む183グラフを、異なる非ループの端点集合の個数から求める式と照合した。
