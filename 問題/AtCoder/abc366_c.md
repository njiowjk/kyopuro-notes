# C - Balls and Bag Query

## 問題概要

空の袋から始め、`Q`、続けて `Q` 件のクエリを読む。`1 x` で値 `x` を1個追加、`2 x` でその値を持つ要素を1個削除し、`3` で現在の値の種類数を出力する。`1 <= Q <= 2×10^5`、`1 <= x <= 10^6`。削除する値は袋内に存在し、`3` は1件以上ある。

## 解法の概要

値をキーとする疎な頻度表と、頻度が正の値の種類数を保持する。加算で頻度が `0 → 1` なら種類数を増やし、減算で `1 → 0` なら減らす。一度の操作では対象の値の頻度しか変わらず、他の遷移では種類数も変わらない。ハッシュ表を使う保存済みコードの期待時間は1操作 O(1)、全体で O(Q)。メモリはこれまでに追加された異なる値の数を `U` として O(U)。

主分類は [配列](../../分野/配列/配列.md)。

## 問題固有の実装ポイント

- `3` の行には `x` がない。操作種別と残りの引数を分け、`1`・`2` のときだけ引数を読む。
- 同じ値が複数あるとき、1個消しても頻度が正なら種類数は変わらない。
- 保存済み実装は頻度0のキーを保持するため、辞書の `len` を種類数としては使えない。0のキーを削除する設計なら、辞書サイズで種類数を返せる。

## 自作コード

Inbox で照合した Python のローカルスナップショット（取得元 `atc-rs-local`）を参照した。提出との対応とジャッジ結果は未確認。

`defaultdict(int)` の `cnt` に個数を置く。追加は増やした直後に `cnt[x] == 1` を確認する。削除は減らす直前に `cnt[x] == 1` かを確認して `ans` を調整する。`3` は `ans` をそのまま出す。値の上限までの配列を作る必要はない。

検証では全2サンプルと、空の袋・重複追加・最後の1個の削除を含む100系列を、袋そのものを持つ実装と照合した。
