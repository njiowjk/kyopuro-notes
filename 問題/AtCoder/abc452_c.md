# C - Fishbones

## 問題概要

長さ `N` の脊椎候補と、肋骨ごとの条件 `(A_i,B_i)` を考える。各肋骨に長さ `A_i`、`B_i` 文字目が脊椎の `i` 文字目と等しい辞書内の文字列を置けるか、辞書の各候補について `Yes` / `No` を出力する。`1 <= B_i <= A_i <= 10`、`1 <= N <= 10`、`M <= 2×10^5`。辞書の英小文字列は互いに異なり、長さは `1..10`。

## 解法の概要

辞書を一度走査し、長さと文字位置の組ごとに出現する文字を集合に集める。各候補は長さが `N` で、すべての `i` について候補の `i` 文字目が対応する集合に含まれるときに成立する。肋骨の文字列は独立に選べ、同じ文字列を何度でも再利用できるので、各位置の存在判定で十分。

辞書の全文字数を `S`、長さ `N` の候補数を `M_N`、最大長を `L`、文字種数を `Σ` とする。`std::set` を使う保存済み実装は、時間 O(L²+M+(S+N M_N) log(Σ+1))、辞書を含むメモリ O(S+M+N+L²Σ)。

主分類は [文字列](../../分野/文字列/文字列.md)。

## 問題固有の実装ポイント

- `A_i` と `B_i` は1始まりで、長さ・位置の表では両方を0始まりに変換する。
- 長さが `N` であることを先に判定する。肋骨の文字列に脊椎と同じ文字列を選ぶこともできる。

## 自作コード

C++ の照合済み実装は `set<char>` の二次元表を作り、辞書の文字列を長さと位置で振り分ける。入力順に全候補を判定し、条件を表す集合の `count` を呼ぶ。 本人の提出との対応とジャッジ結果は未確認。

照合済み実装で公式サンプル全2件と、指定位置が末尾、長さ不一致、指定の長さや文字が存在しないケースを確認した。
