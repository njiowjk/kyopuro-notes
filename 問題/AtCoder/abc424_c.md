# C - New Skill Acquired

## 問題概要

`N` と各スキルの組 `(A_i,B_i)` を読む。`(0,0)` のスキルは習得済みで、残りは指定された二つのうち少なくとも一方を習得すると解放される。最終的に習得できる個数を出力する。`1 <= N <= 2×10^5`、前提がある場合は両方の番号が `1..N`。

## 解法の概要

前提スキルから解放先へ有向辺を張り、初期習得済みのスキルを全部キューに入れて多点 BFS を行う。キューへ追加する時点で習得済みにする。一つの前提をたどるだけで次のスキルを習得できるため、始点から到達した頂点は全て習得できる。逆に初期状態にないスキルは、どれか一つの習得済み前提を経由してしか増えない。辺は高々 `2N` 本なので、時間・追加メモリともに O(N)。

主分類は [グラフ](../../分野/グラフ/グラフ.md)。

## 問題固有の実装ポイント

- `(0,0)` を始点にする分岐を先に行い、前提のある行だけ番号を0始まりに直す。
- 前提番号の重複や自己参照があっても、訪問済み配列で重複を防ぐ。始点から届かない循環は一斉に習得できない。始点がなければ答えは0。
