# C - Tallest at the Moment

## 解法の概要

`N` 人の身長 `H_i` と退出時刻 `L_i`、`Q` 個の整数時刻 `T` を読み、各 `T+1/2` に残っている人の最大身長を入力順に出力する。退出時刻は非減少順で、`1 <= N,Q <= 3×10^5`、`1 <= H_i,L_i <= 10^9`、`0 <= T < L_N`。各時刻には1人以上残る。

ローカル実装は全員の身長を重複ありの順序付き集合に入れ、クエリを時刻順に処理する。時刻 `T` までの退出を順に消し、その時点の集合の最大値を答えとして保持する。各人の削除は1回だけ。C++ の `multiset` で同じ方針を実装する場合、整列を含め時間 O(N log(N+1) + Q log(Q+1))、入力・クエリを含む作業メモリ O(N+Q)。

退出時刻が整列済みなので、残る人は常に接尾区間になる。各位置 `i` から末尾までの身長の最大値 `suffix[i]` を前計算し、`upper_bound(L.begin(), L.end(), T)` で求めた位置 `i` の `suffix[i]` を答える。この構成ではクエリを入力順に処理でき、時間 O(N + Q log(N+1))、クエリを逐次処理する場合の作業メモリ O(N)。主分類は [配列](../../分野/配列/配列.md)。

## 問題固有の実装ポイント

- `T+1/2` では整数の退出時刻について `L_i <= T` の人が退出済み。同じ時刻に退出する人をすべて除いてから答える。
- 同じ身長の人が複数いる場合、退出した人数分だけ削除する。時刻が同じクエリの答えは共通。クエリを並べ替えた場合も結果は元の順番で出す。

## 自作コード

Inbox で照合した Python のローカルスナップショットを参照した。提出との対応とジャッジ結果は未確認。

`go` に退出時刻と身長の組を降順に置き、`go` の末尾から該当する組を取り除く。身長は `SortedList` から1個ずつ消し、末尾の最大値を時刻をキーにした辞書に保存する。入力時のクエリ列を使って辞書から元の順番で出力する。

Python 版は退出・クエリの整列に O(N log(N+1) + Q log(Q+1))、保持用に O(N+Q) を使う。`SortedList` の追加・削除はライブラリの目安で各 O(log(N+1))、末尾参照は O(1)。辞書の更新と参照は平均 O(1)。

外部依存を読み込める一時環境で、公式サンプル2件、小規模入力での全員走査との照合、重複する身長・退出時刻・クエリ時刻、`N = Q = 3×10^5` のケースを確認した。
