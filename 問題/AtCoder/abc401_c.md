# C - K-bonacci

## 問題概要

`N K` を読み、`0 <= i < K` なら `A_i=1`、`i >= K` なら `A_i` は直前 `K` 項の和と定義される。`A_N` を `10^9` で割った余りを出力する。`1 <= N,K <= 10^6` で、`K>N` もあり得る。

## 解法の概要

`P[i]` を先頭 `i` 項の和とする。`i>=K` では必要な区間和が既に求まっているため、`A_i=P[i]-P[i-K]` を定数時間で計算できる。これを足して `P[i+1]=2P[i]-P[i-K]` と更新する。`i<K` では `P[i+1]=P[i]+1`。`P[0]=0` から順に計算すれば各段階で定義どおりの累積和が得られ、加減算だけなので各値を法 `10^9` の余りで保存してよい。時間・追加メモリは O(N)。

主分類は [配列](../../分野/配列/配列.md)。

## 問題固有の実装ポイント

- `A_0` から `A_N` まで `N+1` 項ある。最後に使う累積和の位置は `N` と `N+1`。
- `K>N` なら全項が1、`K=1` なら前の1項を引き継ぐため全項が1。C++ に移す場合は差が負になる場合の剰余を正規化する。
