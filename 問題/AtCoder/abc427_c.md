# C - Bipartize

## 問題概要

`N` 頂点 `M` 辺の単純無向グラフから辺を削除して二部グラフにするための最小削除数を求める。`2 <= N <= 10`、`1 <= M <= N(N-1)/2`。

## 解法の概要

各頂点を白か黒のどちらかに割り当てる全パターンをビットで列挙する。色分けを固定すると、両端が同色の辺はすべて削除が必要で、異なる色の辺はすべて残せる。よって各色分けの同色辺数を数え、最小値を取ればよい。

時間 O(2^N M)、辺リストを含むメモリ O(M)。

主分類は [グラフ](../../分野/グラフ/グラフ.md)。

## 問題固有の実装ポイント

- 既に二部グラフなら、同色辺が0になる色分けが存在する。孤立頂点の色は答えに影響しない。
- 全色を反転しても各辺の端点の一致・不一致は変わらない。最後の頂点を片方の色に固定しても必要な候補が残る。

## 自作コード

Python の照合済み実装は1始まりの頂点番号をそのままビット位置に使う。`2^N` 未満のマスクではビット0が未使用、ビット `N` が常に0になる。したがって最後の頂点を固定した色分けを各2回調べるが、色反転の対称性により最小値は変わらない。0始まりの頂点番号に変換すると全色分けを素直に列挙できる。 本人の提出との対応とジャッジ結果は未確認。

照合済み実装で公式サンプル全3件と、三角形、孤立頂点、頂点数が上限の完全グラフを確認した。
