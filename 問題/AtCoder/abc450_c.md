# C - Puddles

## 問題概要

`H W` と `H` 行の盤面を読む。`.` を白、`#` を黒とし、白マスの4近傍連結成分のうち最外周のマスを一つも含まない成分の個数を出力する。`3 <= H,W <= 10^3`。

## 解法の概要

まず外周の各白マスから到達できる白マスを訪問済みにする。これで外周に接する成分をすべて除外できる。次に残った白マスを走査し、見つけるたびに BFS で成分全体を訪問済みにして答えを1増やす。2段階で訪問済みを共有すれば、各白マスがキューに入るのは最大1回なので時間・追加メモリはともに O(HW)。

主分類は [グリッド](../../分野/グリッド/グリッド.md)。

## 問題固有の実装ポイント

- 4近傍だけを使うため、外周の白マスに斜めで接するだけの内側の成分は数える。外周を処理した後は内側だけを走査できる。
- 訪問済みの印はキューへ追加するときに付ける。白マスが全域につながる場合や白マスがない場合、答えは0。

## 自作コード

Inbox で照合したローカルソースを解析した。提出との対応とジャッジ結果は未確認。

Python の `visited` とキューではマスを `row*W+col` で管理する。外周は未訪問の白マスに出会うたびにその成分の BFS を終え、次に内側の未訪問の白マスを起点に同じ探索をする。近傍を調べるときは行・列の範囲を確かめてから盤面と訪問済み配列にアクセスする。

全2サンプルと、成分ごとに外周との接触を判定する実装との照合を行い、全白・全黒・斜めだけで外周に接する場合も確認した。
