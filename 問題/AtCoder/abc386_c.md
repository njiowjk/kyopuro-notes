# C - Operate 1

## 問題概要

`K`、英小文字列 `S`、`T` をこの順で読む。`S` に1文字の挿入・削除・置換を合計 `K` 回以内行って `T` と一致させられるかを `Yes` / `No` で出力する。この問題では `K = 1` で、両文字列の長さは1以上500,000以下。

## 解法の概要

長さの差で可能な操作を絞る。同じ長さなら対応位置の不一致が1個以下、長さが1違うなら長い方から1文字除いて短い方にできればよい。差が2以上なら1回の操作では一致しない。

短い方の長さを `m`、最長の共通接頭辞と共通接尾辞の長さを `p`、`q` とする。長い方から位置 `k` を除くには、削除位置より前の `k` 文字と後ろの `m-k` 文字が一致すればよい。つまり `k <= p` かつ `m-k <= q` を満たす `k` があることと `p+q >= m` は同値。最悪時間 O(|S| + |T|)、入力を除く追加メモリ O(1)。

主分類は [文字列](../../分野/文字列/文字列.md)。

## 問題固有の実装ポイント

- `K` の入力行は読むが、その値が常に1なので判定には使わない。
- 接頭辞・接尾辞の走査はそれぞれ短い方の長さで打ち切る。長さの差を反映するため、末尾側は両文字列それぞれの末尾から数える。
- 先頭・末尾の挿入と、同じ文字が連続して `p+q` が `m` を超えるケースも許す。等長で一致済みなら操作0回。

## 自作コード

`ls`、`lt` で分岐し、等長なら `diff` に不一致数を数える。挿入・削除の2分岐では短い方の長さに合わせて `left` と `right` を別々に増やし、合計が短い方の長さ以上かを比較する。`Counter` は使っていない。C++化では短い方と長い方の役割を揃え、長さ差1の走査を共通化できる。
