# B - Grid Rotation

## 問題概要

`N` と `N×N` の白黒グリッド `S,T` を読む。`S` の1マスの色変更と全体の時計回り90度回転を使い、`T` に一致させる最小操作数を出力する。`1 <= N <= 100`。

## 解法の概要

色変更の後に回転する操作は、先に回転し、移動先のマスの色を変える操作と同じ結果になる。したがって回転を先にまとめてよく、4回の回転は省ける。`k=0,1,2,3` について、`k` 回回した盤面と目標の不一致数を数え、`k` と不一致数の和の最小値を求める。各不一致は1回ずつ変更する必要があり、それだけで一致する。時間・追加メモリ O(N²)。

主分類は [グリッド](../../分野/グリッド/グリッド.md)。

## 問題固有の実装ポイント

- 行が下向き、列が右向きの0始まり座標では、時計回りの1回転で `(i,j)` が `(j,N-1-i)` に移る。
- `N=1` や回転対称の盤面でも、回転0回の候補を含める。回転数と不一致数を足して候補を比較する。

## 自作コード

元の盤面の各列を下から上へ読み、新しい盤面の各行にする。回転前の盤面から順に不一致を数え、比較ごとに1回回転する。4候補を記録して最小値を出力する。

公式2サンプルと、1マス、一致済み、回転だけで一致する場合、小さな盤面を全操作で幅優先探索した最短手数を照合した。
