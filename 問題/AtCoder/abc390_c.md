# C - Paint to make a rectangle

## 問題概要

`H×W` の盤面の `?` を黒か白で塗り、すべての黒マスを1つの軸平行な長方形にできるかを判定する。`1 <= H,W <= 1000`。固定の黒マス `#` は少なくとも1つ存在し、固定の白マス `.` は塗り替えられない。

## 解法の概要

固定の黒マスすべてを含む最小の外接長方形を、行・列の最小値と最大値から作る。どの候補長方形もその範囲を含むため、内側に固定の白マスが1つでもあれば失敗する。内側に白がなければ、その内側の `?` を黒、外側の `?` を白にすれば条件を満たす。

最初に盤面全体を走査し、次に外接長方形の中だけを調べる。時間 O(HW)、盤面を含めたメモリ O(HW)、判定に使う追加メモリ O(1)。

主分類は [グリッド](../../分野/グリッド/グリッド.md)。

## 問題固有の実装ポイント

- 行・列とも両端を含めて検査する。1マス、1行、1列の長方形も許される。
- 四隅が固定の黒である必要はない。固定された白が問題になるのは外接長方形の中だけ。

## 自作コード

Python の照合済み実装は、行と列の端を番兵値で初期化し、`#` を見つけたときだけ極値を更新する。黒マスが1つ以上あるため極値は確定する。長方形を再走査して `.` を見つけたら即座に `No` を出す。 本人の提出との対応とジャッジ結果は未確認。

照合済み実装で公式サンプル全3件と、1行・1列、固定の白マスが外接長方形の中または外にあるケースを確認した。
