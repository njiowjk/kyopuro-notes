# C - Rotate and Sum Query

## 問題概要

長さ `N` の整数列を読み、`Q` 件のクエリを順に処理する。`1 c` は左に `c` 個回転し、`2 l r` は現在の1始まり閉区間 `[l, r]` の和を1行に出力する。`1 <= N, Q <= 2×10^5`、`1 <= A_i <= 10^9`、`1 <= c <= N`、`1 <= l <= r <= N`。区間和クエリが少なくとも1件ある。

## 解法の概要

初期配列の累積和 `P[k]` を先頭 `k` 要素の和として構築し、初期配列上の現在の先頭をオフセット `s` で管理する。左回転を `c` 回行うたびに `s = (s + c) % N`。現在の位置 `i` は初期配列の0始まり位置 `(i - 1 + s) % N` に対応する。

変換した両端を `L, R` とすると、`L <= R` なら `P[R+1] - P[L]`。`L > R` なら末尾側と先頭側に分かれるので `P[N] - P[L] + P[R+1]`。和を取る区間の長さは高々 `N` で、初期配列の境界をまたぐのは高々1回。前処理 O(N)、各クエリ O(1)、全体 O(N + Q)、追加メモリ O(N)。

主分類は [配列](../../分野/配列/配列.md)。

## 問題固有の実装ポイント

- `c = N` で先頭位置は変わらない。`N = 1`、`l = r`、回転後の全区間 `[1,N]` も同じ式で扱える。
- 累積和と答えは最大 `2×10^14`。C++では `long long` を使い、回転量は更新のたびに剰余を取る。
