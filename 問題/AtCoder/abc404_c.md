# C - Cycle Graph?

## 問題概要

`N` 頂点 `M` 辺の単純無向グラフが、全頂点を1周する1つのサイクルだけからなるかを `Yes` / `No` で出力する。`3 <= N <= 2×10^5`、`0 <= M <= 2×10^5`。

## 解法の概要

辺を1本ずつ読み、両端の次数を増やすとともに Union-Find で両端を併合する。判定条件は、全頂点の次数が2で、全頂点が同じ連結成分にあること。単純グラフの全頂点の次数が2なら、各連結成分はサイクルになる。成分が1つなら、グラフ全体が1つのサイクルになる。

経路短縮とサイズによる併合により、時間 O(N+M α(N))、追加メモリ O(N)。

主分類は [グラフ](../../分野/グラフ/グラフ.md)。

## 問題固有の実装ポイント

- 次数2の条件だけでは、互いに素な複数のサイクルを受理してしまう。連結だけでも、道や枝のあるグラフを受理してしまう。
- 自己ループと多重辺は入力にない。孤立頂点があれば連結性の条件を満たさない。

## 自作コード

Python の照合済み実装は `atcoder.dsu.DSU` を使い、頂点番号を0始まりに変換する。次数表に現れる値の集合が `{2}` であり、頂点0を含む成分のサイズが `N` かを調べる。次数表には孤立頂点の項目が作られないが、成分のサイズが `N` のときは孤立頂点がない。 本人の提出との対応とジャッジ結果は未確認。

照合済み実装で公式サンプル全2件と、サイクル、道、孤立頂点、辺なし、分離した2つのサイクルを確認した。 Python の DSU は一時環境に用意した ac-library-python を使った。
