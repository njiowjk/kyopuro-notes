# C - Black Intervals

## 問題概要

`N Q` と1始まりの反転位置 `A_1,...,A_Q` を読む。初めは全マスが白。1点の白黒を反転するたびに、黒が連続する極大区間の個数を1行ずつ出力する。`1 <= N,Q <= 5×10^5`。

## 解法の概要

各マスの色と黒区間数を持つ。白いマスを黒に変えると、隣の黒が0個なら区間が1個生まれ、1個なら伸びるだけで、2個なら二つの区間がつながる。黒から白への変化では対応する増減が逆になる。反転位置と隣接する区間だけが変わるため、各更新は O(1)。初期化を含め O(N+Q) 時間、色の保持に O(N)、照合済み実装はクエリ位置の配列にも O(Q) を使う。

主分類は [配列](../../分野/配列/配列.md)。

## 問題固有の実装ポイント

- 端では盤面外を白と考える。`N=1` の場合は、同じ位置を反転するたびに答えが1と0を行き来する。
- 区間を数える条件を「自分が黒で、左隣が白」にすると、変更前後に調べる位置は反転箇所とその右隣だけになる。
