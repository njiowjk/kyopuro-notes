# C - Adjacent Sums (easy)

## 問題概要

`N M`、長さ `N` の `A`、長さ `N-1` の `B` を読む。1回の操作で `A` の1要素に1を足し、すべての隣接和の `M` による余りを `B_i` に合わせる最小操作数を出力する。C問題では `M = 2`、`2 <= N <= 2×10^5` で、入力の `A_i, B_i` は0か1。

## 解法の概要

変更後の偶奇 `p` を固定した位置の費用は、元の偶奇と同じなら0、異なれば1。`dp[i][p]` を位置 `i` までの隣接条件を満たし、現在位置を偶奇 `p` にする最小費用とする。先頭は各偶奇への変更費用で初期化する。

隣接和の余りは XOR と同じ。現在位置の偶奇 `p` を決めると、直前位置の偶奇は `p ^ B[i-1]` に一意に決まる。その状態の費用に現在位置の変更費用を足す。最後の2状態の小さい方が答え。時間 O(N)、保存済み実装の追加メモリは O(N)。直前の行だけ残せば入力配列を除く追加メモリは O(1)。

主分類は [配列](../../分野/配列/配列.md)。

## 問題固有の実装ポイント

- 0始まりで位置 `i-1` と `i` をつなぐ条件は `B[i-1]`。`B[i-1] = 0` なら同じ偶奇、1なら逆の偶奇へ遷移する。
- 1回ずつ足す操作は、目標の偶奇への最小費用が0か1になる。`M > 2` では2状態と XOR の式を使えない。
- 先頭には隣接条件がなく、`N = 2` では遷移が1回。既に全条件を満たす場合は0回。
