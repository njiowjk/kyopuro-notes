# C - Merge the balls

## 問題概要

`N` と `N` 個の指数 `A_i` を読む。大きさ `2^A_i` のボールを順に末尾に追加し、末尾2個が同じ大きさの間はその2個を和の大きさの1個に置き換える。全操作後の個数を出力する。`1 <= N <= 2×10^5`、`0 <= A_i <= 10^9`。

## 解法の概要

列に残っているボールの指数をスタックに持つ。大きさが等しい条件は指数の一致と同値で、同じ `x` を2個併合すると `2^x+2^x=2^(x+1)` になる。追加の直後と併合の直後に末尾2個を見れば、問題の各操作を順番どおりに再現できる。追加が `N` 回あり、併合1回で個数が1減るため、併合は全体で高々 `N-1` 回。時間・追加メモリは O(N)。

主分類は [配列](../../分野/配列/配列.md)。

## 問題固有の実装ポイント

- 指数をそのまま使えば、巨大な `2^A_i` を計算しなくてよい。この問題の併合規則は指数を1増やすだけで表せる。
- 末尾2個の比較前に列の長さが2以上かを調べる。併合でできたボールがその前のボールと同じ大きさなら再び併合する。離れた位置にある同値のボールはそのまま残す。
