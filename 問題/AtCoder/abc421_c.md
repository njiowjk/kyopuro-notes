# C - Alternated

## 解法の概要

`N` と `A`、`B` を `N` 個ずつ含む長さ `2N` の文字列を読み、隣接文字の交換で交互に並べる最小回数を出力する。`1 <= N <= 5×10^5`。

目標は `ABAB…` と `BABA…` の2通り。どちらかを固定し、ある一方の文字の `k` 番目の出現を、目標列での同じ出現順に対応させる。異なる文字の隣接交換1回で、追っている文字が1つだけ1マス動くので、対応する位置の差の絶対値の和が下限になる。左から最初に食い違う位置に右側の最も近い必要な文字を運ぶと、途中は反対の文字だけで、交換ごとにその距離の和を1減らせる。したがって下限に達し、2目標の費用のうち小さい方が答えになる。

時間 O(N)。ローカル実装の入力文字のリストは O(N)、そのほかの追加メモリは O(1)。主分類は [文字列](../../分野/文字列/文字列.md)。

## 問題固有の実装ポイント

- 0始まりで偶数位置に来る文字の目標添字は `0, 2, 4, …`。偶数位置に置く文字を選ぶと、もう一方の目標位置も決まる。
- 同じ移動を両方の文字について足すと二重に数える。すでに交互なら答えは0。片方の文字がすべて先に並ぶ入力では交換数が二次の大きさになるため、C++ では合計を `long long` で持つ。

最初の走査では `A` を偶数位置に、次の走査では `B` を偶数位置に移す場合の費用を求める。対象文字に出会うたびに現在の添字と目標添字 `coll` の差の絶対値を足し、`coll` を2進める。

公式サンプル3件、`N = 1..4` の全98文字列を対象とした隣接交換の BFS、上限の長さで `A` と `B` がそれぞれ固まったケースを確認した。
