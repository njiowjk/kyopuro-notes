# C - Sugoroku Destination

## 問題概要

`N` と整数列 `A` を読む。マス `i` からは `A_i` に移動する。各始点から `10^100` 回移動したあとのマスを、始点順に空白区切りで1行に出力する。`1 <= N <= 5×10^5`、`i <= A_i <= N`。

## 解法の概要

移動先は自分自身か、より大きい番号のマス。番号が変わる移動は高々 `N-1` 回なので、操作後の答えは最初に到達する固定点 `A_i = i`。各始点から固定点かメモ済みのマスまでたどり、経路上の全マスに同じ行き先を記録する。そこから先の遷移は始点に依存しないため、以後は記録を再利用できる。

固定点以外のマスを未計算の状態でたどるのは全体で高々1回。固定点またはメモ済みのマスで止まる処理は各始点で1回なので、時間 O(N)、追加メモリ O(N)。主分類は [グラフ](../../分野/グラフ/グラフ.md)。

## 問題固有の実装ポイント

- 入力される行き先は1始まり、配列添字は0始まり。固定点の判定と、出力時の番号変換をそろえる。
- `N = 1` や全マスが固定点の場合もその場で停止する。固定点以外の閉路を許す入力では別途閉路判定が必要。
- 既存のメモ化の考え方を使い、長い経路では明示的な配列に経路を積んでから結果を書けば、再帰の深さに依存しない。`A_i >= i` を使い、後ろから確定してもよい。
