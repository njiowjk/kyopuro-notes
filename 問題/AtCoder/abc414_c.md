# C - Palindromic in Both Bases

## 問題概要

基数 `A` と上限 `N` を読み、`1..N` のうち十進表記と `A` 進表記の両方が回文になる整数の総和を出力する。`2 <= A <= 9`、`1 <= N <= 10^12`。総和は符号付き64ビット整数に収まる。

## 解法の概要

十進の桁数ごとに先頭の半分を列挙する。回文の後半は前半から一意に決まり、奇数桁では中央の桁を一度だけ使う。先頭桁を1以上にすれば、正の十進回文を重複なく列挙できる。各候補を `A` 進に変換して両端から比較し、一致した候補だけを足す。

`N` の十進桁数を `D` とすると、候補数は上界 O(10^⌈D/2⌉)、生成と判定を含めて時間 O(D × 10^⌈D/2⌉)、追加メモリ O(D)。

主分類は [整数](../../分野/整数/整数.md)。

## 問題固有の実装ポイント

- 同じ桁数では前半が大きいほど候補も大きいため、初めて `N` を超えた時点でその桁数の走査を打ち切れる。`N` 自体は範囲に含む。
- 1桁ではコピーする後半が空になる。`A` 進変換の余りは、`A <= 9` なので数字1文字で表せる。

## 自作コード

C++ の照合済み実装では、前半の文字列を反転して後半を作る。奇数桁では反転前に末尾を落とす。候補が上限以下なら、`A` で割った余りを桁文字に変え、左右の対応する文字がすべて同じかを調べる。 本人の提出との対応とジャッジ結果は未確認。

照合済み実装で公式サンプル全3件と、上限ちょうどの回文、桁数が変わる境界、最大の上限を確認した。
