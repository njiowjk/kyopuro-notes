# C - Count Arithmetic Subarrays

## 解法の概要

`N` と長さ `N` の正整数列 `A` を読み、等差数列になっている連続区間の数を出力する。`1 <= N <= 2×10^5`、`1 <= A_i <= 10^9`。

長さ2以上の区間は、その区間内の隣接差がすべて同じときに等差数列になる。同じ差が連続する極大区間を走査し、差が `m` 個並ぶ区間から `m(m+1)/2` 個を加える。これはその区間内で選べる空でない差分区間の数で、それぞれ元の配列の長さ2以上の区間に一意に対応する。長さ1の区間 `N` 個を最後に足す。

差分をその場で計算するので、時間 O(N)、入力配列を除く追加メモリ O(1)。主分類は [配列](../../分野/配列/配列.md)。

## 問題固有の実装ポイント

- 差分のまとまりの長さは元の要素数より1小さい。隣り合うまとまりは元配列上で端の要素を1つ共有するので、長さ1の区間は別に足す。
- `N = 1` なら差分は空で答えは1。差が0の区間や負の差が続く区間も同じように数える。
- 最大値は全区間が等差数列の場合の `N(N+1)/2`。C++ では積から `long long` で計算する。

走査位置 `l` から最初の差 `d` を求め、同じ差が続く間だけ `l` と差分の個数 `cnt` を進める。まとまりを抜けるたびに三角数を加算する。各隣接差を処理する回数は定数回で、差分配列を持たなくてよい。

公式サンプル3件、短い配列での全区間列挙との照合、単一要素、公差が負・0の区間、20万要素が等しいケースを確認した。
