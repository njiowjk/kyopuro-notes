# B - Christmas Trees

## 問題概要

`A M L R` を読み、整数 `k` に対する位置 `A+kM` のうち閉区間 `[L,R]` に入るものの個数を出力する。`-10^18 <= A,L,R <= 10^18`、`1 <= M <= 10^9`、`L<=R`。位置や添字は負になり得る。

## 解法の概要

原点を `A` にずらすと `L-A <= kM <= R-A`。`M>0` より、許される整数 `k` は `ceil((L-A)/M)` から `floor((R-A)/M)` まで。閉区間なので上下端の差に1を足す。`L<=R` で該当なしなら下端が上端よりちょうど1大きく、個数は0。時間・追加メモリともに O(1)。

主分類は [整数](../../分野/整数/整数.md)。

## 問題固有の実装ポイント

- 負の座標差を `M` で割ると、C++ の `/` は0方向に丸める。割り切れない負数の床は商より1小さく、割り切れない正数の天井は商より1大きい。
- `L==R` なら、唯一の座標が対象と一致するときだけ1。差の絶対値は最大 `2×10^18`、個数は最大 `2×10^18+1` で `long long` に収まる。
