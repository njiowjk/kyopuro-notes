# C - Brackets Stack Query

## 問題概要

空の括弧列に `Q` 個のクエリを順に適用する。`1 c` は `(` または `)` を末尾に追加し、`2` は空でない列の末尾を削除する。各操作の直後に正しい括弧列かを `Yes` / `No` で出力する。`1 <= Q <= 8×10^5`。

## 解法の概要

左括弧を `+1`、右括弧を `-1` とした残高を考える。すべての接頭辞で残高が非負なら、右括弧が現れるたびに未対応の左括弧と組にできる。列全体の残高が0なら左括弧も余らない。この2条件を各長さの残高と接頭辞最小値で判定する。末尾操作だけなので、追加時は状態を1つ積み、削除時は状態を1つ捨てればよい。全体で償却 O(Q) 時間、最大の列長を `L` として追加メモリ O(L+1)。

主分類は [文字列](../../分野/文字列/文字列.md)。

## 問題固有の実装ポイント

- 履歴の初期状態を残高0、最小値0とする。空接頭辞を含むため、接頭辞最小値は非負判定を `== 0` で行える。
- 全体の残高が0でも `)(` は無効。最後の文字を削除して空になれば `Yes`。末尾以外の編集には別の更新方法が要る。
