# C - Avoid Knight Attack

## 問題概要

`N M` と `M` 個の駒の1始まり座標を読み、既存の駒が置かれておらず、ナイトの移動でどの駒からも取られないマス数を出力する。`1 <= N <= 10^9`、`1 <= M <= 2×10^5`。駒の座標はすべて異なり、盤面外のマスは数えない。

## 解法の概要

各駒の座標と、8通りの移動差分を加えて盤内に収まる座標を同じ集合に入れる。集合には置けないマスがすべて入り、別々の駒の移動先が重なったり、移動先に別の駒がいたりしても1回だけ数えられる。盤面全体の `N*N` からこの集合のサイズを引く。

列挙する座標は高々 `9*M` 個。Python のハッシュ集合では期待時間 O(M)、追加メモリ O(M)。主分類は [グリッド](../../分野/グリッド/グリッド.md)。

## 問題固有の実装ポイント

- 8通りは行・列の差の絶対値が `1` と `2` になる組。座標の軸を入れ替えた場合と両軸の符号をすべて含める。
- 座標を1始まりで扱い、移動先は両軸が `1..N` のときだけ登録する。`N = 1` では既存の駒のマスだけが登録される。
- C++17 では `set<pair<int, int>>` で座標を重複排除できる。時間は O(M log(M+1)) で、`N*N` は掛ける前に `long long` に広げる。
