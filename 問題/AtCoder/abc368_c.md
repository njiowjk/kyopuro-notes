# C - Triple Attack

## 問題概要

`N` 個の体力 `H_i` を先頭から順に減らす。全体の手番 `T` を1増やすごとに、残っている先頭の敵の体力を `T` が3の倍数なら3、それ以外なら1減らす。全員を倒し終わる手番を出力する。`1 <= N <= 2×10^5`、`1 <= H_i <= 10^9`。

## 解法の概要

どの位相から始めても連続3手の合計ダメージは5になる。現在の敵の体力 `h` について `h/5` 周期をまとめて消化し、残った `h%5` だけを1手ずつ処理する。各ダメージは正なので、体力より小さい総ダメージの周期では途中で敵を倒さない。体力と総ダメージが等しい場合も、最後の1手でちょうど倒す。

残りは3手以内で処理できるため時間 O(N)。保存済み実装は体力を保持するためメモリ O(N)。逐次入力なら追加メモリ O(1)。

主分類は [整数](../../分野/整数/整数.md)。

## 問題固有の実装ポイント

- 周期をまとめても `T mod 3` は変わらない。敵が切り替わっても `T` は引き継ぐ。
- 体力が5の倍数なら端数処理は0手。最後の一撃の超過ダメージは次の敵に持ち越さない。C++ では累計手番に `long long` を使う。

## 自作コード

Python の照合済み実装は、各敵で `T` に周期分の手数を加え、体力から周期分のダメージを引く。その後は `T` を1増やしてから剰余を調べ、体力が0以下になるまで繰り返す。 本人の提出との対応とジャッジ結果は未確認。

照合済み実装で公式サンプル全3件と、体力が周期合計の倍数になるケース、敵をまたぐ位相を確認した。
