# C - Comfortable Distance

## 問題概要

`N L R` と英小文字列 `S` を読む。`S_i=S_j` かつ `L <= j-i <= R` を満たす添字ペア数を出力する。`2 <= N <= 5×10^5`、`1 <= L <= R <= N-1`。

## 解法の概要

0始まりで左端 `i` を固定すると、右端候補は閉区間 `[i+L,min(i+R,N-1)]`。この窓の文字頻度を持てば、`S[i]` と一致する候補数をそのまま答えに足せる。`i` を1進めるごとに左から1文字を除き、右端がまだ文字列内なら1文字を加える。各ペアは左端の処理時に1回だけ数えるので、時間 O(N)、文字列の保持を除く追加メモリ O(26)。

主分類は [文字列](../../分野/文字列/文字列.md)。

## 問題固有の実装ポイント

- 最初に右側の `[L,R]` の頻度を作る。左端の候補は `i+L < N` の間だけ存在し、右端が末尾に着いたあとは窓を縮める。
- `L=R` なら窓の幅は高々1。最大で二次個のペアがあるため、C++ では答えに `long long` を使う。

## 自作コード

Inbox で照合した Python の実装を確認した。提出との対応とジャッジ結果は未確認。

`defaultdict(int)` に右側の窓の文字数を持つ。現在の `i` の頻度を足した後で左境界の文字を削り、右境界が `N-1` に達していなければ次の文字を加える。

公式3サンプルと、`L=R`、窓が末尾に接する場合、32ビット整数を超えるペア数、短い列で全候補ペアを数えた結果を照合した。
