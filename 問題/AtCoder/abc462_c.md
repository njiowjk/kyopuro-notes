# C - Not Covered Points

## 問題概要

`N` と点 `(X_i,Y_i)` を読む。原点と点 `i` を対角とする軸平行長方形の内部に別の点を含まないような `i` の個数を出力する。辺上は内部に含めない。`1 <= N <= 3×10^5`、`X` と `Y` はそれぞれ `1..N` の順列。

## 解法の概要

座標が全て正なので、内部に点がある条件は `x < X_i` かつ `y < Y_i` の点が存在すること。点を `x` の昇順に並べると、処理済みの点はちょうど `x` が小さい点全体になる。その `y` の最小値が現在の `y` より小さいかだけを調べればよい。`Y` が重複しないので、最小値を厳密に更新した回数が答えになる。整列込み O(N log N) 時間、点とソートの作業領域に O(N)、走査だけなら O(1) の追加メモリ。

主分類は [配列](../../分野/配列/配列.md)。

## 問題固有の実装ポイント

- `N=1` なら答えは1。`x` の昇順で `y` が全て降順なら全点を数え、全て昇順なら最初の1点だけを数える。
- 範囲と重複なしの制約を使えば、`x` を添字として `y` を直接配置し O(N) で並べられる。一般の入力で同じ `x` を許す場合は、そのグループを判定し終えてから最小値を更新する。

## 自作コード

Inbox で照合した Python の実装を確認した。提出との対応とジャッジ結果は未確認。

`x`、`y` をともに1減らしてタプルにし、辞書順に整列する。この平行移動は座標同士の大小関係を保つ。初期の最小値に十分大きい値を置き、`y` がそれより小さいときにだけ最小値と答えを更新する。

公式3サンプルと、1点、座標が単調な場合、短い入力で全ての点対を比較する判定を照合した。
