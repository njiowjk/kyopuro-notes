# C - Candy Tribulation

## 問題概要

`N X Y` と `N` 個の `A_i` を読む。各人に重量 `X` と `Y` の飴を合計 `A_i` 個ずつ渡し、全員の総重量が等しくなるようにする。成立する場合は重い飴の合計個数の最大値、成立しない場合は `-1` を出力する。`2 <= N <= 2×10^5`、`1 <= A_i <= 10^9`、`1 <= X < Y <= 10^9`。

## 解法の概要

重い飴の個数を `t_i` とすると、総重量は `A_i*X+t_i*(Y-X)` で `0<=t_i<=A_i`。全員の候補は公差 `d=Y-X` の有限等差数列なので、まず剰余が全員一致し、閉区間 `[max(A_i*X), min(A_i*Y)]` が空でないことが必要。剰余が一致すれば、この上端は誰かの列の末項であり、共通剰余も満たす。重い飴の個数は共通重量に対して全員とも増加するため、上端を選べば合計も最大になる。時間 O(N)、入力を除く追加メモリ O(1)。

主分類は [整数](../../分野/整数/整数.md)。

## 問題固有の実装ポイント

- `d>0` は保証される。上下端が等しい場合も候補になる。剰余が異なる場合は上下端が重なっていても成立しない。
- 重量の積は `10^18` まで、合計個数は `2×10^14` までなので、C++ では積を取る前から `long long` を使う。
