# C - Distance Indicators

## 問題概要

`N` と正整数列 `A` を読み、`1 <= i < j <= N` で `j - i = A_i + A_j` となる組の総数を出力する。`1 <= N, A_i <= 2×10^5`。

## 解法の概要

条件式を `i + A_i = j - A_j` と変形し、左側と右側の添字から独立にキーを作る。全添字の `i + A_i` の頻度を数え、各 `j` に対して `j - A_j` の頻度を答えに足す。キーが一致した組は `j - i = A_i + A_j > 0` を満たし、必ず `i < j` になる。各組は右側の添字 `j` の処理で1回だけ加算される。

ハッシュ表で期待時間 O(N)、追加メモリ O(N)。主分類は [配列](../../分野/配列/配列.md)。

## 問題固有の実装ポイント

- 両方の添字を0始まりに直しても等式の両辺から1を引くだけなので、同じ判定になる。`j - A_j` が負になる場合もある。
- 同じキーを作る複数の添字はすべて数える。`N = 1` なら0で、最大制約ではペア数が32ビット整数の範囲を超え得る。
- 正値の保証を使えない類題では、左から走査して未登録の現在位置で照会し、それから現在位置の左キーを頻度表へ登録すると、`i < j` を保てる。
