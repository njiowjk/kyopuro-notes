# B - Langton's Takahashi

## 問題概要

`H×W` のトーラス状の盤面はすべて白で始まる。左上で上を向いた状態から `N` 手後の盤面を出力する。各手で現在の色を反転し、元の色が白なら右、黒なら左に90度回り、1マス進む。`1 <= H,W <= 100`、`1 <= N <= 1000`。

## 解法の概要

盤面、現在の座標、向きを保持して1手ずつ処理する。向きを上・右・下・左の順の循環する添字にすれば、回転は添字の増減、移動は対応する座標差の加算で表せる。各手の移動直後に盤面の端を反対側へつなげることで、次の手も有効なマスから始められる。

初期化と出力を含む時間 O(HW+N)、盤面を含むメモリ O(HW)。

主分類は [グリッド](../../分野/グリッド/グリッド.md)。

## 問題固有の実装ポイント

- 色で回転方向を決めるのは反転前。移動に使うのは回転後の向き。
- 横は幅 `W`、縦は高さ `H` で折り返す。幅・高さが1の軸では、進んでも同じ座標になる。

## 自作コード

C++ の照合済み実装は、列 `x` と行 `y` を分けて盤面を `a[y][x]` で参照する。上下左右の移動量を配列に持ち、向きが `4` または `-1` になったら循環させる。毎回1マス移動なので、はみ出す座標は上限ちょうどか `-1` のいずれかになる。 本人の提出との対応とジャッジ結果は未確認。

照合済み実装で公式サンプル全3件と、縦横の折り返し、片方または両方の軸の長さが1の盤面を確認した。
