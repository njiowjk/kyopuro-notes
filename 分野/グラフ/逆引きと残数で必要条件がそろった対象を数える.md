# 逆引きと残数で必要条件がそろった対象を数える

## やりたいこと

条件が一度ずつ成立し、成立後は取り消されないとき、全条件が成立した対象の数を各更新後に答える。条件と対象を二部グラフの頂点と見なし、条件側の隣接リストを作る。

## 基本的な考え方

条件ごとに、対応する対象のリストを持つ。各対象の未成立数を初期化し、条件が成立するたびにそのリストにある対象だけの残数を減らす。

## 実装（C++）

`abc402_c` の入力に対応する例。`N M`、各対象の条件数と1始まりの条件番号、最後に `N` 個の成立順を読む。各対象内の条件番号は相異なり、成立順は `1..N` の順列。元の入力で重複がないため、逆引きは集合から `vector` に置き換える。条件数0の対象も初期状態で数えられる形にする。


```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    vector<vector<int>> dependents(n);
    vector<int> remaining(m);
    int ready = 0;
    for (int target = 0; target < m; ++target) {
        cin >> remaining[target];
        if (remaining[target] == 0) ++ready;
        for (int j = 0; j < remaining[target]; ++j) {
            int condition;
            cin >> condition;
            dependents[condition - 1].push_back(target);
        }
    }

    for (int day = 0; day < n; ++day) {
        int condition;
        cin >> condition;
        for (int target : dependents[condition - 1]) {
            if (--remaining[target] == 0) ++ready;
        }
        cout << ready << '\n';
    }
}
```

## 実装の要点

未成立の条件だけが `remaining` に残る。条件成立時にその逆引きリストを走査すれば、影響を受ける対象だけの残数を1減らせる。初期状態から残数0の対象と `1 → 0` に移った対象を1回ずつ数える。

## 計算量・注意点

条件と対象を結ぶ辺の総数を `E` とすると時間・追加メモリともに O(N+M+E)。同一条件の再通知を許す場合は通知済みを記録する。同じ条件が一対象内で重複する入力では、事前に重複を除く。
