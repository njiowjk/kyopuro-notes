# 無向グラフから自己ループと多重辺を除く

## やりたいこと

無向グラフの頂点をすべて残し、自己ループと多重辺を除くために必要な最小削除辺数を求める。端点が逆順で与えられた辺も同じ無向辺とみなす。

## 基本的な考え方

自己ループはすべて削除する。他の辺は端点を小さい順に揃え、同じ端点対は初出の1本を残す。

## 実装（C++）

`abc393_c` の形式で頂点数 `n` と辺数 `m`、続けて `m` 行の端点 `u v` を読む。端点は1〜`n`。

```cpp
#include <iostream>
#include <set>
#include <utility>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    set<pair<int, int>> seen;
    int removed = 0;

    for (int edge = 0; edge < m; ++edge) {
        int u, v;
        cin >> u >> v;
        if (u == v) {
            ++removed;
            continue;
        }

        if (u > v) swap(u, v);
        const bool inserted = seen.emplace(u, v).second;
        if (!inserted) ++removed;
    }

    cout << removed << '\n';
}
```

## 実装の要点

- `u == v` なら `removed` を増やし、その辺の処理を終える。
- 他の辺は `u < v` に揃えて `seen.emplace(u, v)` する。戻り値の `second` が偽なら、その対から既に1本を残しているので削除数を増やす。
- 自己ループは1本も残せず、非ループの各端点対は最大1本を残せる。各対の初出を残すと、その最大本数を同時に達成できる。
- 保存済みPython実装は両方の端点順で既出判定する。この例は端点を正規化するので、集合を調べるのは1回で済む。

## 計算量・注意点

異なる非ループ辺の数を `U` として時間 O(m log(U + 2))、追加メモリ O(U)。辺が0本なら答えは0。有向グラフで順序に意味がある場合は端点を正規化しない。
