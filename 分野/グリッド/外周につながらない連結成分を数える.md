# 外周につながらない連結成分を数える

## やりたいこと

長方形グリッドで、通行可能なマスからなる4近傍連結成分のうち、外周のマスを含まないものを数える。

## 基本的な考え方

外周の通行可能マスを BFS の始点にし、そこから到達できる範囲を訪問済みにする。残った通行可能マスを始点として BFS を繰り返し、新しい BFS を始めた回数を数える。

## 実装（C++）

`abc450_c` の入力に対応する例。`H W` と `.`・`#` のグリッドを読み、囲まれた `.` の成分数を出力する。幅・高さは1以上とする。ローカル実装は訪問済み配列を持つが、この例では入力グリッドを変更できる前提で、キューへ入れたマスを `#` にする。外周の始点はまとめてキューに入れる。


```cpp
#include <iostream>
#include <queue>
#include <string>
#include <utility>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int h, w;
    cin >> h >> w;
    vector<string> grid(h);
    for (string& row : grid) cin >> row;

    queue<pair<int, int>> cells;
    const int dr[] = {-1, 1, 0, 0};
    const int dc[] = {0, 0, -1, 1};
    auto enqueue = [&](int row, int col) {
        if (grid[row][col] != '.') return;
        grid[row][col] = '#';
        cells.emplace(row, col);
    };
    auto flood = [&] {
        while (!cells.empty()) {
            const auto [row, col] = cells.front();
            cells.pop();
            for (int d = 0; d < 4; ++d) {
                const int r = row + dr[d];
                const int c = col + dc[d];
                if (0 <= r && r < h && 0 <= c && c < w) enqueue(r, c);
            }
        }
    };

    for (int row = 0; row < h; ++row) {
        enqueue(row, 0);
        enqueue(row, w - 1);
    }
    for (int col = 0; col < w; ++col) {
        enqueue(0, col);
        enqueue(h - 1, col);
    }
    flood();

    int enclosed = 0;
    for (int row = 1; row + 1 < h; ++row) {
        for (int col = 1; col + 1 < w; ++col) {
            if (grid[row][col] != '.') continue;
            ++enclosed;
            enqueue(row, col);
            flood();
        }
    }
    cout << enclosed << '\n';
}
```

## 実装の要点

外周の通行可能マスから到達できるマスは、外周に触れる成分の和集合と一致する。残った `.` を見つけるたびに成分全体を消すと、同じ成分を再び数えずに済む。

## 計算量・注意点

時間 O(HW)、キューの追加メモリは最悪 O(HW)。キューへの追加時に訪問済みにするので、角を複数回調べても追加は1回。盤面を維持するなら別に訪問済み配列を使う。斜めの接触も連結とする場合は、両段階の近傍を8方向にそろえる。
