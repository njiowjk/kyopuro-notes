# 必須マスの外接長方形に禁止マスがないか判定する

## やりたいこと

必須マスをすべて含み、禁止マスを含まない軸平行な長方形が存在するか調べる。必須マスは少なくとも1つあり、その他のマスは自由に含められる。幅・高さ・面積には追加条件がない。

## 基本的な考え方

必須マスの行と列の最小値・最大値から、全必須マスを含む最小の長方形を作る。どの候補もこの長方形を含む。内側に禁止マスがなければ、この長方形を選べる。

## 実装（C++）

`abc390_c` の入力形式で `#`（必須）、`.`（禁止）、`?`（自由）からなる盤面を読み、長方形を作れるか答える。照合済み実装と同じ2回の走査を使い、番兵を盤面の寸法から決める。

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

int main() {
    int height, width;
    std::cin >> height >> width;
    std::vector<std::string> grid(height);
    int top = height;
    int bottom = -1;
    int left = width;
    int right = -1;

    for (int row = 0; row < height; ++row) {
        std::cin >> grid[row];
        for (int col = 0; col < width; ++col) {
            if (grid[row][col] == '#') {
                top = std::min(top, row);
                bottom = std::max(bottom, row);
                left = std::min(left, col);
                right = std::max(right, col);
            }
        }
    }

    for (int row = top; row <= bottom; ++row) {
        for (int col = left; col <= right; ++col) {
            if (grid[row][col] == '.') {
                std::cout << "No\n";
                return 0;
            }
        }
    }
    std::cout << "Yes\n";
}
```

## 実装の要点

- `top` と `left` は行数と列数、`bottom` と `right` は `-1` で始め、`#` を見たときだけ四辺を更新する。必須マスが1つ以上あるので四辺は有効な座標に定まる。
- 四辺を含む範囲を走査し、`.` があれば不可。なければ内側の `?` を黒く、外側を白くできる。

## 計算量・注意点

盤面を `H` 行 `W` 列とすると、時間 O(HW)、盤面を含むメモリ O(HW)、盤面以外は O(1)。高さまたは幅が1の長方形も扱える。必須マスが0個の入力も扱う場合は、空の長方形を許すかどうかに応じて別途判定する。
