# 公差が同じ有限等差数列の共通最大値を求める

## やりたいこと

共通の正の公差 `d` を持つ1本以上の有限等差数列について、共通する最大値を求める。各列は初項 `first` から末項 `last` まで、両端を含めて `d` ずつ増え、範囲外の項や欠番はない。負の端点や1項だけの列も扱う。

## 基本的な考え方

各列の候補を「初項から末項までの範囲」と「公差で割った余り」で表す。全列の初項が同じ剰余を持つことを確かめながら、共通範囲の下端と上端を更新する。

## 実装（C++）

### 基本実装

`N d` と、各列の初項・末項 `first last` を `N` 組読む。各値は `long long` の範囲とし、`N >= 1`、`d > 0`。共通最大値を整数で、共通値がない場合や端点が等差数列を表さない場合は `No` と出力する。`-1` も共通最大値になり得る。

```cpp
#include <algorithm>
#include <iostream>
#include <limits>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n, d;
    if (!(cin >> n >> d) || n <= 0 || d <= 0) {
        cout << "No\n";
        return 0;
    }

    auto normalized_mod = [d](long long value) {
        const long long r = value % d;
        return r < 0 ? r + d : r;
    };

    long long low = numeric_limits<long long>::lowest();
    long long high = numeric_limits<long long>::max();
    long long residue = -1;
    for (long long i = 0; i < n; ++i) {
        long long first, last;
        if (!(cin >> first >> last) || first > last) {
            cout << "No\n";
            return 0;
        }
        const long long r = normalized_mod(first);
        if (normalized_mod(last) != r || (residue != -1 && r != residue)) {
            cout << "No\n";
            return 0;
        }

        residue = r;
        low = max(low, first);
        high = min(high, last);
    }

    if (low <= high) cout << high << '\n';
    else cout << "No\n";
}
```

### ABC432 C への応用

`N X Y` と `N` 個の `A_i` を読む。制約は `2 <= N <= 2×10^5`、`1 <= A_i <= 10^9`、`1 <= X < Y <= 10^9`。全員にちょうど `A_i` 個ずつ渡すので、人 `i` の総重量の候補は初項 `A_i*X`、末項 `A_i*Y`、公差 `Y-X` の有限等差数列になる。

共通重量 `high` が決まれば、各人に渡す大きい飴の数は、その列の0始まりの添字 `(high-A_i*X)/(Y-X)` に等しい。共通重量が上がるほど全員の添字が増えるので、共通最大値で添字を合計する。共通値がない場合は問題の指定に従って `-1` を出力する。

```cpp
#include <algorithm>
#include <iostream>
#include <limits>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    long long x, y;
    cin >> n >> x >> y;
    vector<long long> count(n);
    for (long long& a : count) cin >> a;

    const long long step = y - x;
    const long long residue = count.front() * x % step;
    long long low = 0;
    long long high = numeric_limits<long long>::max();
    for (long long a : count) {
        const long long first = a * x;
        if (first % step != residue) {
            cout << -1 << '\n';
            return 0;
        }
        low = max(low, first);
        high = min(high, a * y);
    }

    // high はいずれかの列の末項なので、剰余も一致する。
    if (low > high) {
        cout << -1 << '\n';
        return 0;
    }
    long long total = 0;
    for (long long a : count) total += (high - a * x) / step;
    cout << total << '\n';
}
```

## 実装の要点

`low` はこれまでの初項の最大値、`high` は末項の最小値。各列に入る整数は、その列の閉区間にあり、初項と同じ剰余を持つものに限る。初項の剰余が1つでも違う場合や `low > high` の場合は共通値がない。剰余が一致して区間が重なる場合、`high` は実際にいずれかの列の末項なので、その剰余も全列の初項と一致する。したがって `high` が全列に含まれ、これより大きい値は少なくともその列の範囲外になる。

基本実装では両端の剰余も比較して、末項まで公差 `d` ずつ進めるかを確認する。ABC432 C では `A_i*Y = A_i*X+A_i*(Y-X)` から、この条件が自動的に成立する。照合済みコードの上端の切り下げは、上端が実際の末項であることを使って応用例では省略できる。

## 計算量・注意点

- 基本実装は時間 O(N)、追加メモリ O(1)。端点同士を引かず、範囲の比較と剰余だけで判定する。負の剰余にだけ `d` を足せば結果は `[0, d)` に収まり、`d` が `long long` の最大値でも加算があふれない。端点を式から作る用途では、積や和を評価する前に整数型の範囲を確認する。
- 応用例は時間 O(N)。個数を後から合計するため `A_i` の配列に O(N) を使い、そのほかの追加メモリは O(1)。重量の積は最大 `10^18`、大きい飴の合計は最大 `2×10^14` なので `long long` に収まる。
