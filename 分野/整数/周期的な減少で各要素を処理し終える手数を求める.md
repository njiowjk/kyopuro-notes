# 周期的な減少で各要素を処理し終える手数を求める

## やりたいこと

各手の減少量が正で周期的に繰り返されるとき、対象を先頭から順に処理し終える手数を求める。各手は現在の1要素に作用し、余った減少量は捨てる。全体の手番は次の要素に引き継ぐ。

## 基本的な考え方

どの位相から始めても連続した1周期の減少量の和は同じ。現在の値をその和で割った商の分だけ周期を飛ばし、余りを手番に従って1手ずつ減らす。

## 実装（C++）

`abc368_c` の入力形式で体力を読み、減少量 `1, 1, 3` の繰り返しで最後の要素を処理し終える手番を出力する。照合済み実装の剰余による分岐を周期表に置き換え、体力を1個ずつ読み込む。

```cpp
#include <array>
#include <iostream>
#include <numeric>

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);

    int n;
    std::cin >> n;
    const std::array<int, 3> damage{1, 1, 3};
    const int period = static_cast<int>(damage.size());
    const int per_period = std::accumulate(damage.begin(), damage.end(), 0);
    long long turns = 0;

    for (int i = 0; i < n; ++i) {
        long long health;
        std::cin >> health;
        turns += (health / per_period) * period;
        health %= per_period;

        while (health > 0) {
            health -= damage[turns % period];
            ++turns;
        }
    }
    std::cout << turns << '\n';
}
```

## 実装の要点

- `turns` は消化済みの手数。`health / per_period` 周期分の手数を加えても、次の位相 `turns % period` は変わらない。
- 各手の減少量は正なので、1周期の途中までの減少量は周期全体の和未満。体力が周期合計の倍数でも、飛ばした最後の周期の末尾でちょうど0になる。
- 端数を処理する間だけ次の減少量を表から読み、手数を1増やす。体力が0以下になったら次の対象へ進み、手数だけを引き継ぐ。

## 計算量・注意点

対象数を `N`、周期長を `P` とすると、残りは対象ごとに高々 `P` 手で消化できるので、時間 O(P+NP)、メモリ O(P)。例では `P=3` なので時間 O(N)、メモリ O(1)。累積手数は `long long` で保持する。周期表を変更する場合は周期内の和を持つ型も確認する。
