# 閉区間に含まれる等差数列の項数を数える

## やりたいこと

任意の整数 `k` に対する `a+k*m` のうち、閉区間 `[l,r]` に含まれる項の個数を求める。`m>0`、`l<=r` とし、座標と `k` は負でもよい。

## 基本的な考え方

`m` が正なので、`l <= a+k*m <= r` を `k` の上下限に変形できる。最小の整数添字を天井除算、最大の整数添字を床除算で求め、両端を含めて数える。

## 実装（C++）

`abc334_b` の入力に対応する例。`a m l r` を読み、個数を出力する。ローカル実装の床・天井の分岐を、符号付き商に剰余の符号を反映する形にまとめる。


```cpp
#include <iostream>
using namespace std;

int main() {
    long long a, m, l, r;
    cin >> a >> m >> l >> r;

    const long long left = l - a;
    const long long right = r - a;
    const long long first = left / m + (left % m > 0);
    const long long last = right / m - (right % m < 0);
    cout << last - first + 1 << '\n';
}
```

## 実装の要点

許される添字は `ceil((l-a)/m)` 以上、`floor((r-a)/m)` 以下。C++ の整数除算は0方向に丸めるので、正の剰余なら天井を1増やし、負の剰余なら床を1減らす。`l<=r` なら、有効な添字がない場合は `first == last+1` になる。

## 計算量・注意点

時間・追加メモリともに O(1)。両端を含むので個数は `last-first+1`。剰余が0なら商を変えない。例は座標差・添字差・個数が符号付き64ビット整数に収まる範囲で使う。
