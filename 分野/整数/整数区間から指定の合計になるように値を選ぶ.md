# 整数区間から指定の合計になるように値を選ぶ

## やりたいこと

各整数閉区間から値を1つずつ独立に選び、指定された総和になる列を1つ構成する。各区間では下限から上限までのすべての整数を選べるものとする。

## 基本的な考え方

選べる総和の下限と上限は、それぞれ全要素を下限と上限に置いたときの総和。下限から始め、目標までの差を各区間の幅の範囲で順に足す。

## 実装（C++）

`abc362_c` の入力形式で区間の数と各区間の下限・上限を読み、総和0の列があればその一例を出力する。照合済み実装で不足分を求めるために作っていた下限の累積和を、省略して総和だけを持つ。増分は `min` の1式で求める。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    int n;
    std::cin >> n;
    std::vector<long long> value(n), upper(n);
    long long lower_sum = 0;
    long long upper_sum = 0;
    for (int i = 0; i < n; ++i) {
        std::cin >> value[i] >> upper[i];
        lower_sum += value[i];
        upper_sum += upper[i];
    }

    constexpr long long target = 0;
    if (target < lower_sum || upper_sum < target) {
        std::cout << "No\n";
        return 0;
    }

    long long remaining = target - lower_sum;
    for (int i = 0; i < n; ++i) {
        const long long added = std::min(remaining, upper[i] - value[i]);
        value[i] += added;
        remaining -= added;
    }

    std::cout << "Yes\n";
    for (int i = 0; i < n; ++i) {
        std::cout << value[i] << (i + 1 == n ? '\n' : ' ');
    }
}
```

## 実装の要点

- `value[i]` を区間の下限で初期化し、`remaining` に目標との差を持つ。目標が両端の総和の間なら、初期の残量は非負で全区間の幅の総和以下になる。
- 各要素では残量と増加可能幅の小さい方を足す。その後の残量は、未処理の要素の幅の総和以下に保たれるので、最後に0になる。

## 計算量・注意点

区間数を `N` とすると時間 O(N)、メモリ O(N)。区間の上下限、総和、差分は `long long` で扱う。0幅の区間もそのまま扱える。飛び飛びの値だけを選べる場合は、総和の上下限の間にあっても構成できないことがある。
