# 変化量に上限のある値が時刻ごとの範囲を満たせるか判定

## やりたいこと

初期値が決まっており、1単位時間あたり高々1だけ連続的に変えられる値が、指定時刻ごとに許容区間へ入れるか判定する。目標は時刻昇順の閉区間とする。境界と時刻が整数なら、連続値を扱う場合も到達区間の両端を整数で管理できる。

## 基本的な考え方

直前の目標までをすべて満たして到達できる値を、閉区間 `[low, high]` で持つ。次の目標までの経過時間 `elapsed` だけ両端を広げ、その時刻の許容区間との共通部分を取る。どこかで共通部分が空なら条件をすべて満たす経路は存在しない。

## 実装（C++）

`abc434_c` の形式でケース数を読み、各ケースで目標数 `n`、初期高度、続けて各目標の時刻と高度の上下限を読む。高度は常に正で、各目標の下限は1以上。この例は照合済み実装と同じ区間更新を使う。下限が正なので目標との交差で高度の下限も満たし、失敗後はそのケースの残りの入力を読む。

```cpp
#include <algorithm>
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int tests;
    cin >> tests;
    while (tests--) {
        int n;
        long long height;
        cin >> n >> height;
        long long low = height;
        long long high = height;
        long long previous = 0;
        bool possible = true;

        for (int i = 0; i < n; ++i) {
            long long time, lower, upper;
            cin >> time >> lower >> upper;
            if (!possible) continue;

            const long long elapsed = time - previous;
            low = max(low - elapsed, lower);
            high = min(high + elapsed, upper);
            possible = low <= high;
            previous = time;
        }

        cout << (possible ? "Yes" : "No") << '\n';
    }
}
```

## 実装の要点

- 時刻0の状態は `low = high = height`。各目標で `elapsed = time - previous` を計算し、`low = max(low - elapsed, lower)`、`high = min(high + elapsed, upper)` に更新する。
- 交差に含まれる各値には、直前の区間内に距離 `elapsed` 以下の出発点がある。正の両端を直線でつなげば、途中も正で変化量の上限を守れる。そのため、更新後の区間はここまでの目標を満たす到達可能な高度全体になる。
- `low > high` が失敗条件。`low == high` のときはその一点に到達できる。最後の目標を満たした後は同じ高度にとどまれる。

## 計算量・注意点

目標数 N の1ケースにつき時間 O(N)、追加メモリ O(1)。時刻差と区間の加減算には `long long` を使う。移動量に下限があるなど、取り得る値の集合が途中で分かれ得る条件では、区間1本で表せるか確認する。
