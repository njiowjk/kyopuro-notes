# 予算以内で選べる要素数を費用の昇順で最大化する

## やりたいこと

要素をそれぞれ高々1回選べるとき、総費用を予算以内に収めながら選択数を最大化する。費用は互いに独立で非負とする。

## 基本的な考え方

費用を昇順に並べる。どの `k` 個を取っても、先頭 `k` 個より費用の合計は小さくならない。予算に収まる最長の接頭辞を選べば最大個数が得られる。

## 実装（C++）

`abc437_c` の入力形式で各ケースの重さと力を読む。全体の力の合計を予算とし、個体を乗せる費用を、増える重さと減る力の和に直す。照合済み実装と同じ昇順走査を使い、次の費用が残予算を超えた時点で終了する。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);

    int tests;
    std::cin >> tests;
    while (tests--) {
        int n;
        std::cin >> n;
        std::vector<long long> cost(n);
        long long budget = 0;
        for (long long& item_cost : cost) {
            long long weight, power;
            std::cin >> weight >> power;
            item_cost = weight + power;
            budget += power;
        }

        std::sort(cost.begin(), cost.end());
        int count = 0;
        for (long long item_cost : cost) {
            if (item_cost > budget) {
                break;
            }
            budget -= item_cost;
            ++count;
        }
        std::cout << count << '\n';
    }
}
```

## 実装の要点

- `budget` に残り予算、`count` に選択数を持つ。次の費用が残予算以下ならその費用を引き、選択数を1増やす。
- 費用が残予算と等しければ選べる。次が選べなければ、それ以降は同じかそれ以上の費用なので、そこで確定する。

## 計算量・注意点

1ケースの要素数を `N` とすると時間 O(N log N)、メモリ O(N)。費用と予算は `long long` で扱う。入力された力の総和と重さ・力の加算の両方をその型で計算する。
