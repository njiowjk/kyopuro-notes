# 回転する配列の区間和を累積和で求める

## やりたいこと

要素の値が固定された配列に対して、左回転と区間和の取得を繰り返す。回転後の任意の連続区間の和を、1クエリ O(1) で求めたい。配列は空でなく、問い合わせる区間の長さは配列長以下とする。

## 基本的な考え方

元の配列に累積和を作る。回転で変わるのは現在の先頭が元の配列のどこを指すかなので、0始まりの位置 `offset` だけを動かす。現在の配列で指定された区間を元の配列上に戻すと、末尾をまたぐ場合だけ2つに分かれる。

## 実装（C++）

`abc425_c` の形式で長さ `n`、クエリ数 `q`、配列の要素を読む。`1 steps` は先頭から `steps` 個を末尾へ移し、`2 left right` は1始まり閉区間の和を出力する。照合済み実装と同じく元の配列1周分の累積和を使い、この例は回転のたびに剰余を取ってオフセットを一定の範囲に保つ。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;
    vector<long long> prefix(n + 1);
    for (int i = 0; i < n; ++i) {
        long long value;
        cin >> value;
        prefix[i + 1] = prefix[i] + value;
    }

    int offset = 0;
    while (q--) {
        int type;
        cin >> type;
        if (type == 1) {
            int steps;
            cin >> steps;
            offset = (offset + steps) % n;
        } else {
            int left, right;
            cin >> left >> right;

            const int first = (offset + left - 1) % n;
            const int end = first + (right - left + 1);
            if (end <= n) {
                cout << prefix[end] - prefix[first] << '\n';
            } else {
                cout << prefix[n] - prefix[first] + prefix[end - n] << '\n';
            }
        }
    }
}
```

## 実装の要点

- `prefix[k]` は初期配列の先頭 `k` 個の和。`prefix[0] = 0` から順に作る。
- `offset = 0` で開始し、左回転のたびに `(offset + steps) % n` に更新する。現在の位置 `left` は元の `first = (offset + left - 1) % n` に対応する。
- 元の配列上で `first` を起点に `right - left + 1` 個ぶん進んだ位置を、終端を含まない `end` とする。`end <= n` なら差分1回。`end > n` なら `[first, n)` と `[0, end - n)` の和を足す。区間長が `n` 以下なので、境界をまたぐのは高々1回。

## 計算量・注意点

累積和の構築 O(N)、各クエリ O(1) で、全体 O(N + Q)、追加メモリ O(N)。`end == n` は末尾でちょうど終わる。全区間の照会、1要素の照会、`steps == n` も同じ式で扱える。例の `1 <= steps <= n <= 2×10^5` では `offset + steps` が `int` に収まり、累積和と答えは `long long` で保持する。
