# 同じ値をまとめて追加し先頭から取り出した合計を求める

## やりたいこと

整数列の末尾に同じ値を指定個数だけ追加し、先頭から指定個数を取り除いたときの合計を求める。追加と取り出しを入力順に処理し、取り出す個数はその時点の列の長さ以下とする。

## 基本的な考え方

1回の追加を `(残個数, 値)` の1組にまとめ、キューに追加する。取り出すときはキューの先頭から必要な個数だけ消費し、取り出した個数と値の積を合計する。

## 実装（C++）

`abc413_c` の形式でクエリ数 `Q` を読み、`1 c x` で値 `x` を `c` 個追加し、`2 k` で先頭の `k` 個を取り出した合計を出力する。照合済み実装では配列と先頭添字を使う。この例ではキューの先頭から消費済みの組を取り除く。

```cpp
#include <algorithm>
#include <iostream>
#include <queue>
#include <utility>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int q;
    cin >> q;
    queue<pair<long long, long long>> blocks;
    while (q--) {
        int type;
        cin >> type;
        if (type == 1) {
            long long count, value;
            cin >> count >> value;
            blocks.emplace(count, value);
        } else {
            long long remaining;
            cin >> remaining;
            long long sum = 0;
            while (remaining > 0) {
                auto& [count, value] = blocks.front();
                const long long taken = min(remaining, count);
                sum += taken * value;
                remaining -= taken;
                count -= taken;
                if (count == 0) blocks.pop();
            }
            cout << sum << '\n';
        }
    }
}
```

## 実装の要点

- `blocks` の各組を先頭から残個数ぶん展開すると、現在の列に一致する。同じ値の追加が続く場合も、クエリごとに別々の組として扱える。
- `remaining` は今回まだ取り出す必要のある個数。先頭の組から `min(remaining, count)` 個を取り出し、その寄与を `sum` に加える。`remaining` と `count` から同じ個数を引くので、合計と残りの列を同時に更新できる。
- `count` が0になった組はすぐに `pop()` する。取り出しが組の終端と一致する場合も同じ。途中まで消費した組は、更新した残個数で先頭に残る。

## 計算量・注意点

各組を取り除くのは高々1回で、組の途中で止まる処理は取り出しクエリ1回につき高々1回。全 `Q` クエリで時間 O(Q)、追加メモリは同時に保持する組数の最大値に比例し、最悪 O(Q)。

列が空になっても次の追加から処理を再開できる。問題の制約では取り出し1回の答えが最大 `10^18` になるため、掛け算の時点から `long long` を使う。
