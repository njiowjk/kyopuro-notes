# 一対一の割り当てに必要な追加枠の最小容量を求める

## やりたいこと

正の要求値が `N` 個、既存枠の容量が `N-1` 個ある。容量が要求値以上の枠に1件ずつ割り当てるとき、追加する1枠に必要な最小容量を求める。

## 基本的な考え方

要求と既存枠を整列し、未処理の最大の要求を、未使用の最大の既存枠と比較する。入ればその既存枠を使う。入らない場合は追加枠を使い、その要求値を記録する。

## 実装（C++）

`abc376_c` の形式で `N`、おもちゃ `N` 個の大きさ、箱 `N-1` 個の大きさを読み、買い足す箱の最小サイズを出力する。割り当てが不可能なら `-1` を出力する。照合済み実装では配列の末尾を削除する。この例では添字を減らすことで未処理の範囲を管理する。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> demand(n), capacity(n - 1);
    for (int& value : demand) cin >> value;
    for (int& value : capacity) cin >> value;
    sort(demand.begin(), demand.end());
    sort(capacity.begin(), capacity.end());

    int box = n - 2;
    int extra_capacity = 0;
    for (int i = n - 1; i >= 0; --i) {
        if (box >= 0 && demand[i] <= capacity[box]) {
            --box;
        } else if (extra_capacity == 0) {
            extra_capacity = demand[i];
        } else {
            cout << -1 << '\n';
            return 0;
        }
    }
    cout << extra_capacity << '\n';
}
```

## 実装の要点

- `i` は未処理の最大の要求、`box` は未使用の最大の既存枠を指す。容量が要求値以上なら割り当てて `box` を1つ減らす。
- 最大の要求が最大の既存枠に入るなら、この組を先に確定できる。実行可能な割り当てで最大の既存枠を別の要求が使っていた場合、最大の要求が使っていた枠には、その別の要求も入る。2件を交換できるので、同じ追加容量で実行可能な割り当てが残る。
- 最大の既存枠でも足りない場合や既存枠が尽きた場合は、追加枠を使う必要がある。`extra_capacity` にその要求値を記録する。残りをすべて既存枠に割り当てられれば、その容量で足りる。追加枠がもう一度必要になれば不可能。

## 計算量・注意点

整列込みで時間 O(N log N)、整列後の走査は O(N)。配列の保持に O(N)、配列と整列の作業領域を除く追加メモリは O(1)。

同じ大きさの要求と枠も組にできる。`box` が `-1` なら既存枠は使い切っている。要求値は正なので、追加枠をまだ使っていないことを `extra_capacity = 0` で表せる。
