# 隣接する偶奇の条件を満たす最小変更回数を求める

## やりたいこと

各隣接ペアの和の偶奇を指定通りにするため、配列の要素に1を足す操作の最小回数を求める。各位置の変更費用はその位置で決まり、隣接条件は2つの位置の偶奇だけで決まる。ここで使う2状態の XOR 遷移は法 `M = 2` 専用。

## 基本的な考え方

各位置で、末尾が偶数の場合と奇数の場合の最小費用を持つ。隣接する2値の和の偶奇は XOR に等しい。現在位置の偶奇を `parity` とすると、直前の偶奇は `parity ^ required` に一意に決まる。対応する最小費用に現在位置の変更費用を足す。

## 実装（C++）

`abc467_c` の形式で `n`、`m`、長さ `n` の `A`、長さ `n-1` の `B` を読む。`m = 2`、`n >= 2`、`A` と `B` の各値は0か1。照合済み実装の条件分岐を XOR の式にまとめ、直前の2費用だけを保持する。

```cpp
#include <algorithm>
#include <array>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;  // m = 2
    vector<int> a(n);
    for (int& value : a) cin >> value;

    array<int, 2> cost{a[0], 1 - a[0]};
    for (int i = 1; i < n; ++i) {
        int required;
        cin >> required;
        array<int, 2> next{};
        for (int parity = 0; parity < 2; ++parity) {
            next[parity] = cost[parity ^ required] + (a[i] != parity);
        }
        cost = next;
    }

    cout << min(cost[0], cost[1]) << '\n';
}
```

## 実装の要点

- `cost[p]` は処理済みの隣接条件を満たし、末尾の偶奇を `p` にする最小費用。先頭の費用は `{a[0], 1 - a[0]}`。
- `required` は直前と現在の和に指定された偶奇。0なら直前と同じ、1なら逆の偶奇が必要。目標の偶奇が `a[i]` と違うときだけ1回足す。
- 今回の2状態を `next` に計算し終えてから `cost` を置き換える。右端の偶奇は自由なので最後は2状態の小さい方を出力する。

## 計算量・注意点

時間 O(N)。DP の追加メモリは O(1) で、読み込んだ `A` の保持に O(N) を使う。`N = 2` なら更新は1回で、既に条件を満たしていれば答えは0。`M = 2` では1を足すと偶奇が反転するため、各位置の費用は0か1で済む。
