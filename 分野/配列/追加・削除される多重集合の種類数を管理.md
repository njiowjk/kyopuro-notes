# 追加・削除される多重集合の種類数を管理

## やりたいこと

同じ値を複数個持てる集合に1個ずつ追加・削除し、現在入っている値の種類数を答える。削除対象の値はその操作時点で1個以上あるものとする。

## 基本的な考え方

値ごとの頻度を `freq`、頻度が正の値の数を `distinct` に保持する。種類数に影響するのは頻度が0と1の間を移るときだけ。

## 実装（C++）

`abc366_c` の形式でクエリ数 `q` を読み、`1 x` なら追加、`2 x` なら削除、`3` なら種類数を出力する。`3` の行には値が続かない。

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int q;
    cin >> q;
    unordered_map<long long, int> freq;
    int distinct = 0;

    for (int query = 0; query < q; ++query) {
        int type;
        cin >> type;
        if (type == 3) {
            cout << distinct << '\n';
            continue;
        }

        long long x;
        cin >> x;
        int& count = freq[x];

        if (type == 1) {
            ++count;
            if (count == 1) ++distinct;
        } else {
            --count;
            if (count == 0) --distinct;
        }
    }
}
```

## 実装の要点

空の状態から始め、対象値の頻度が追加後に1なら `distinct` を増やし、削除後に0なら減らす。変更される頻度はその値1つだけなので、この2つの遷移を追えば `distinct` と頻度が正のキー数は常に一致する。保存済みコードでは削除前の頻度が1かを調べており、ここでの削除後に0という判定と同じ条件になる。

## 計算量・注意点

`unordered_map` で追加・削除は期待償却 O(1)、種類数の照会は O(1)。全体の期待時間 O(q)。この例は頻度0のキーを残すため、メモリは追加したことのある異なる値の数を `U` として O(U)。頻度が0になった時点でキーを消す設計なら `freq.size()` を種類数に使える。存在しない値の削除を許す場合は、検索でキーが見つかり頻度が正であることを確認してから減らす。
