# 両座標が小さい点のない点を整列と最小値で数える

## やりたいこと

平面上の点 `(x, y)` のうち、`x` と `y` がともに厳密に小さい別の点がないものを数える。片方の座標を基準に整列でき、比較対象が全点で固定されているときに使う。

## 基本的な考え方

点を `x` の昇順に整列する。同じ `x` のグループをまとめて処理し、`min_y` に `x` が真に小さい点だけの `y` の最小値を持つ。この最小値より現在の `y` が大きいとき、両座標が小さい点が存在する。

## 実装（C++）

`abc462_c` の形式で `N` と `N` 組の座標を読む。照合済み実装では `x` と `y` の重複がないため1点ずつ更新している。この例では同じ座標値がある入力にも対応する。

```cpp
#include <algorithm>
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<pair<long long, long long>> points(n);
    for (auto& [x, y] : points) cin >> x >> y;
    sort(points.begin(), points.end());

    int answer = 0;
    long long min_y = 0;
    for (int first = 0; first < n;) {
        int last = first + 1;
        while (last < n && points[last].first == points[first].first) ++last;
        for (int i = first; i < last; ++i) {
            if (first == 0 || points[i].second <= min_y) ++answer;
        }
        if (first == 0 || points[first].second < min_y) {
            min_y = points[first].second;
        }
        first = last;
    }
    cout << answer << '\n';
}
```

## 実装の要点

- グループに入る時点で `min_y` はそれより左のグループだけを反映する。最初のグループには比較対象がないため全点を数える。
- 比較は `y <= min_y`。等しい `y` は厳密に小さい座標の条件を満たさない。判定後にグループの最小 `y` を取り込むことで、同じ `x` の点同士の影響を防げる。

## 計算量・注意点

整列込み O(N log N) 時間、点の保持に O(N)。集計自体の追加メモリは O(1)。過去の最小 `y` と等しい点は、厳密に小さい `y` の点が存在しないので数える。辞書順ソートにより、同一 `x` の最小 `y` はグループの先頭にある。
