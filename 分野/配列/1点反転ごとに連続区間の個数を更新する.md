# 1点反転ごとに連続区間の個数を更新する

## やりたいこと

二値配列の任意の1点を反転するたびに、1 が連続する極大区間の個数を求める。例は初期状態が全て 0 で、入力位置は1始まり。

## 基本的な考え方

極大区間の個数は、左隣が0で自分が1の位置の個数に等しい。位置 `p` を反転して始点条件が変わるのは `p` と `p+1` の2か所なので、反転前後の寄与の差だけを加える。

## 実装（C++）

`abc411_c` の形式で `N Q` と1始まりの反転位置を読む。照合済みの実装が両隣の色で行う場合分けを、区間の始点条件の差分にまとめた。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;
    vector<int> black(n + 2, 0);
    auto starts_run = [&](int i) {
        return black[i] && !black[i - 1];
    };

    int runs = 0;
    for (int query = 0; query < q; ++query) {
        int p;
        cin >> p;
        runs -= starts_run(p) + starts_run(p + 1);
        black[p] ^= 1;
        runs += starts_run(p) + starts_run(p + 1);
        cout << runs << '\n';
    }
}
```

## 実装の要点

- 配列の両端の外側に0を置き、全て白の初期状態では区間数を0にする。
- `starts_run(i)` は位置 `i` が区間の先頭かを返す。更新前の2か所の寄与を引き、反転してから更新後の寄与を足せば、常に現在の先頭の個数になる。

## 計算量・注意点

初期化 O(N)、1反転 O(1)、全体 O(N + Q)、追加メモリ O(N)。両端の外側に 0 を置く。`p=N` では `p+1` の寄与が常に0で、`N=1` も同じ式で処理できる。初期状態が全て0でなければ、全位置の始点を数えてから更新を始める。
