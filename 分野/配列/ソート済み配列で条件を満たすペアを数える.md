# ソート済み配列で条件を満たすペアを数える

## やりたいこと

昇順配列から、`i < j` かつ `a[j] >= threshold` を満たす添字ペアを数える。閾値は左側の添字 `i` ごとに決まる。元の順序に意味がなく、整列しても答えが変わらない場合は先に整列できる。

## 基本的な考え方

`i` を固定すると、有効な `j` は `[i+1,n)` の接尾区間になる。条件を満たす最初の位置が `r` なら `n-r` 個。境界が左に動き得るなら各 `i` で二分探索し、閾値が非減少なら境界を前回から右に進められる。

## 実装（C++）

### 二分探索で毎回境界を求める

閾値が下がる場合も使える。`abc353_c` 形式で `n` と `n` 個の整数を読み、整列して `mod-a[i]` 以上の相手を数える。この例の剰余の集計は `0 <= a[i] < mod` で使える。

```cpp
#include <algorithm>
#include <iostream>
#include <numeric>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<long long> a(n);
    for (long long& x : a) cin >> x;
    sort(a.begin(), a.end());

    constexpr long long mod = 100000000;
    long long wrapped_pairs = 0;
    for (int i = 0; i < n; ++i) {
        const long long threshold = mod - a[i];
        const auto first = lower_bound(a.begin() + i + 1, a.end(), threshold);
        wrapped_pairs += a.end() - first;
    }

    const long long sum = accumulate(a.begin(), a.end(), 0LL);
    cout << (n - 1LL) * sum - mod * wrapped_pairs << '\n';
}
```

### 閾値が非減少なら尺取りで境界を進める

`abc388_c` の入力は `n` と昇順の正整数列 `a`。閾値 `2*a[left]` は `left` を進めても下がらない。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<long long> a(n);
    for (long long& x : a) cin >> x;

    long long pairs = 0;
    int right = 0;
    for (int left = 0; left + 1 < n; ++left) {
        const long long threshold = 2LL * a[left];
        right = max(right, left + 1);
        while (right < n && a[right] < threshold) ++right;
        if (right == n) break;
        pairs += n - right;
    }

    cout << pairs << '\n';
}
```

## 実装の要点

- どちらも開始位置に `i+1` の下限を設け、自分自身と逆順での二重計上を除く。値が重複しても添字が異なれば区別する。
- `abc353_c` の `mod-a[i]` は非増加で、次の `i` で閾値以上になる最初の位置が前回より左に来ることがある。`lower_bound` で有効範囲を毎回調べる。例の `wrapped_pairs` は法以上のペア数で、各要素は剰余を取る前の合計に `n-1` 回現れる。各ペアの和は `2*mod` 未満なので、法以上のペアごとに `mod` を1回引く。
- `abc388_c` では閾値と探索開始位置がともに非減少。前回の `right` より左に有効な相手は現れず、`right == n` なら以後の寄与は0。保存済みコードでは正値の保証だけで自己ペアを除いている。この例では `max(right, left+1)` で添字条件を明示した。

## 計算量・注意点

二分探索版は整列込みで O(n log n)。尺取り版は整列済みの入力に対して O(n) で、`right` の移動は全体で高々 `n` 回。どちらも配列とソートの作業領域を除く追加メモリは O(1)。閾値と等しい値も含める。ペア総数と倍・差・積は `long long` に収まる範囲で扱う。
