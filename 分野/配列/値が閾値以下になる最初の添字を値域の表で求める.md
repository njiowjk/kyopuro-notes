# 値が閾値以下になる最初の添字を値域の表で求める

## やりたいこと

固定配列について、各閾値 `b` に対して `a_i <= b` を満たす最初の添字を求める。値も閾値も正の整数で、上限 `V` に対して答えの表を持てるときに使う。

## 基本的な考え方

入力順に要素を走査する。現在の値を下限として、それ以上でまだ答えのない閾値をまとめて確定する。先に確定した項目は、もっと手前の要素で条件を満たしている。

## 実装（C++）

`abc382_c` の入力形式で配列とクエリを読み、答えの添字を1始まりで出力する。照合済み実装は接頭辞最小値の更新箇所に印を付けてから表を埋める。この例では新たに確定した範囲を読み込み中に埋める。

```cpp
#include <iostream>
#include <vector>

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);

    int n, m;
    std::cin >> n >> m;
    constexpr int max_value = 200000;
    std::vector<int> first_index(max_value + 1, -1);
    int unassigned = max_value;

    for (int index = 1; index <= n; ++index) {
        int threshold;
        std::cin >> threshold;
        while (unassigned >= threshold) {
            first_index[unassigned] = index;
            --unassigned;
        }
    }

    for (int query = 0; query < m; ++query) {
        int value;
        std::cin >> value;
        std::cout << first_index[value] << '\n';
    }
}
```

## 実装の要点

- `first_index` を `-1` で初期化し、`unassigned` に未確定の閾値の最大値を持つ。`unassigned` より大きい値は確定済み。
- 添字 `index` で `threshold` 以上の未確定項目だけを埋める。先行する要素では条件を満たせなかったため、現在の添字が最初になる。
- 同じ値が現れても、対応する閾値には既に先の添字が入っている。最小の配列要素より小さいクエリは `-1` のまま残る。

## 計算量・注意点

配列長を `N`、クエリ数を `M`、値域上限を `V` とすると時間 O(N+M+V)、メモリ O(V)。表の各項目を確定する代入は高々1回。例の `V` は `200000`。値域が広い場合は、接頭辞最小値が下がる箇所だけを保存して閾値ごとに二分探索できる。
