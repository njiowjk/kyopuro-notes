# 等式を左右のキーに分けて添字ペアを数える

## やりたいこと

配列の添字ペア `i < j` のうち、`i` と `j` から独立に求めたキーが一致するものを数える。各キーを O(1) で求められ、キーを比較・ハッシュ化できるときに使う。

## 基本的な考え方

右端 `j` を左から順に走査する。処理時点で、それ以前の添字だけの左キーを頻度表に持つ。現在の右キーに一致する頻度を足してから、現在の左キーを登録する。

## 実装（C++）

`abc417_c` の形式で `n` と `n` 個の整数を読む。条件 `j - i = A_i + A_j` を `i + A_i = j - A_j` に変形し、添字は0始まりで統一する。照合済み実装は正値の保証で全左キーを先に数える。この例は入力を1回走査し、正値の保証を使わずに添字の順序を保つ。

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    unordered_map<long long, int> left_count;
    left_count.reserve(n);
    long long pairs = 0;

    for (int j = 0; j < n; ++j) {
        long long a;
        cin >> a;
        const auto match = left_count.find(j - a);
        if (match != left_count.end()) pairs += match->second;
        ++left_count[j + a];
    }

    cout << pairs << '\n';
}
```

## 実装の要点

- `left_count[k]` は、現在位置より手前で左キーが `k` になった添字の数。表は空で始める。
- `j` で右キー `j - a` の頻度を調べ、該当する添字の数を `pairs` に加える。その後、左キー `j + a` を登録する。照会を先にすることで現在位置は組に含まれない。
- 同じキーの別々の添字はすべて別の組。各組は右端 `j` の処理で1回だけ数える。

## 計算量・注意点

ハッシュ表を使うこの実装の期待償却時間は O(N)、追加メモリは O(N)。負のキーも扱える。要素が1個の場合は0。キーとペア数の計算は `long long` に収まる範囲で使う。例の最大制約では答えが32ビットに収まらない場合がある。
