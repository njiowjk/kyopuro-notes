# 1文字更新後の固定パターン出現数を差分更新

## やりたいこと

1文字ずつ置換される文字列について、固定した空でない短いパターンの出現数を毎回求める。重なる出現は開始位置ごとに数える。

## 基本的な考え方

初めに出現数を全走査で数える。置換位置を含む窓だけについて、変更前の寄与を引き、文字を変え、変更後の寄与を足す。

## 実装（C++）

`abc372_c` の形式で `n q`、空白を含まない長さ `n` の文字列、続けて `q` 行の `pos replacement` を読む。位置は1始まりで有効範囲は1〜`n`。長さとクエリ数は `int` に収まる。別のパターンを使うときは `pattern` を差し替える。

```cpp
#include <algorithm>
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    string s;
    cin >> n >> q >> s;
    const string pattern = "ABC";
    const int length = static_cast<int>(pattern.size());
    const int last_start = n - length;

    int occurrences = 0;
    for (int start = 0; start <= last_start; ++start) {
        if (s.compare(start, length, pattern) == 0) ++occurrences;
    }

    for (int query = 0; query < q; ++query) {
        int pos;
        char replacement;
        cin >> pos >> replacement;
        --pos;

        if (s[pos] == replacement) {
            cout << occurrences << '\n';
            continue;
        }

        const int first = max(0, pos - length + 1);
        const int last = min(pos, last_start);
        for (int start = first; start <= last; ++start) {
            if (s.compare(start, length, pattern) == 0) --occurrences;
        }

        s[pos] = replacement;

        for (int start = first; start <= last; ++start) {
            if (s.compare(start, length, pattern) == 0) ++occurrences;
        }
        cout << occurrences << '\n';
    }
}
```

## 実装の要点

- `occurrences` は現在の文字列にある全出現数。1始まりの `pos` を0始まりに変換する。
- 長さ `L` の窓 `[start,start+L)` が `pos` を含む条件は `pos-L+1 <= start <= pos`。これを有効な開始位置 `[0,n-L]` と交差させ、`first` から `last` まで両端を含めて調べる。
- この範囲外の一致は変化しない。置換の前後で同じ開始位置を調べるため、差分で `occurrences` を保てる。同じ文字への更新では現状を出力する。

## 計算量・注意点

有効な窓数を `W = max(0,n-L+1)` とすると、初回の比較は O(WL)、1更新は最悪 O(1 + min(L,W)×L)。`L` が定数なら入力込みで O(n + q)。文字列とパターンの保持は O(n + L)、走査用の追加メモリは O(1)。`n < L` なら有効な窓は0。保存済みPython実装の長さ3の比較を、C++例では固定パターンとの `compare` に置き換えている。
