# 長さと文字位置を指定して辞書に文字が出現するか判定する

## やりたいこと

固定された辞書に対し、長さ `a` の文字列の位置 `b` に文字 `c` が現れるかを繰り返し調べる。最大長が小さく文字集合が固定されている場合に表を持てる。

## 基本的な考え方

辞書を走査し、`(長さ, 位置)` ごとに見つけた文字を記録する。条件ごとに辞書から独立に選べる場合は、各条件の存在判定をすべて満たせばよい。

## 実装（C++）

`abc452_c` の入力形式で肋骨の条件を先に読み、各辞書項目を脊椎にできるか答える。辞書は長さ10以下の英小文字列。照合済み実装の `set<char>` を26ビットの表に置き換える。

```cpp
#include <array>
#include <bitset>
#include <iostream>
#include <string>
#include <utility>
#include <vector>

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);

    int n;
    std::cin >> n;
    std::vector<std::pair<int, int>> condition(n);
    for (auto& [length, position] : condition) {
        std::cin >> length >> position;
        --position;
    }

    int m;
    std::cin >> m;
    constexpr int max_length = 10;
    std::array<std::array<std::bitset<26>, max_length>, max_length + 1> present{};
    std::vector<std::string> dictionary(m);

    for (std::string& word : dictionary) {
        std::cin >> word;
        for (std::size_t i = 0; i < word.size(); ++i) {
            present[word.size()][i].set(word[i] - 'a');
        }
    }

    for (const std::string& word : dictionary) {
        bool possible = static_cast<int>(word.size()) == n;
        for (int i = 0; possible && i < n; ++i) {
            const auto [length, position] = condition[i];
            possible = present[length][position].test(word[i] - 'a');
        }
        std::cout << (possible ? "Yes" : "No") << '\n';
    }
}
```

## 実装の要点

- `present[length][position]` の第 `c - 'a'` ビットは、その長さ・位置に文字 `c` が出現したことを表す。文字位置は0始まりに変換する。
- 脊椎候補の長さが `n` のときだけ、各位置の文字を対応する肋骨の条件で照会する。肋骨ごとに辞書項目を再利用できるので、同じ候補を他の条件のために予約しておく必要はない。

## 計算量・注意点

最大長を `L`、辞書の項目数と全文字数を `M`、`S`、脊椎の長さと同じ長さ `N` の辞書項目数を `M_N` とする。固定26ビットでの時間は O(L²+S+M+N+N M_N)、メモリは O(L²+S+M+N)。一つの採用文字列で複数位置の条件を同時に満たす場合や、辞書項目の再利用を禁じる場合は、文字列間の対応も管理する必要がある。
