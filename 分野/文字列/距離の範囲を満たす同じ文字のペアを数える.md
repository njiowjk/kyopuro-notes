# 距離の範囲を満たす同じ文字のペアを数える

## やりたいこと

英小文字列で `L <= j-i <= R` かつ `S[i] == S[j]` となるペアを数える。距離の境界は固定で `1 <= L <= R < N` とする。値の一致を判定できる一般のキーにも応用できる。

## 基本的な考え方

右端を `j` に固定すると、左端候補は `[max(0,j-R), j-L]` に限られる。この窓の文字別の頻度を持ち、`S[j]` の頻度を答えに加える。

## 実装（C++）

`abc449_c` の形式で `N L R` と文字列を読む。照合済み実装は左端を固定し右側の窓を管理する。この例は右端を固定し、左側の窓を文字別の固定長配列で管理する。[AtCoder 公式解説](https://atcoder.jp/contests/abc449/editorial/17269)

```cpp
#include <array>
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, left_gap, right_gap;
    string s;
    cin >> n >> left_gap >> right_gap >> s;

    array<int, 26> count{};
    long long answer = 0;
    for (int j = 0; j < n; ++j) {
        const int entering = j - left_gap;
        const int leaving = j - right_gap - 1;
        if (entering >= 0) ++count[s[entering] - 'a'];
        if (leaving >= 0) --count[s[leaving] - 'a'];
        answer += count[s[j] - 'a'];
    }
    cout << answer << '\n';
}
```

## 実装の要点

- 始めは頻度を全て0にする。`j` が1進むごとに新たな候補 `j-L` を入れ、範囲を外れた `j-R-1` を除く。負の位置は飛ばす。
- 頻度更新後に照会することで、距離がちょうど `L` または `R` のペアも含む。各ペアは右端を処理する回だけで数える。

## 計算量・注意点

時間 O(N)、入力以外の追加メモリ O(26)。`L=R` の窓には高々1文字だけ入り、`j<L` の窓は空。ペア数を `long long` で持つ。
