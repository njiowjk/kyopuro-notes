# 1回以内の文字編集で一致するか判定

## やりたいこと

挿入・削除・置換を合わせて高々1回行い、2つの文字列を一致させられるか判定する。各文字を定数時間で比較でき、編集で変わる長さは高々1とする。

## 基本的な考え方

短い方を `s` に揃え、長さが同じなら不一致数を数える。長さが1違うなら、長い方から1文字を除いたときに前後が一致する位置を探す。

## 実装（C++）

`abc386_c` の形式で、`1`、文字列 `s`、`t` を1行ずつ読む。文字列の行が空でも扱える。編集回数の入力がない問題では最初の `k` の読み込みと読み捨てが不要になる。

```cpp
#include <iostream>
#include <limits>
#include <string>
#include <utility>
using namespace std;

int main() {
    int k;
    string s, t;
    cin >> k;  // この例では k = 1
    cin.ignore(numeric_limits<streamsize>::max(), '\n');
    getline(cin, s);
    getline(cin, t);

    if (s.size() > t.size()) swap(s, t);
    const size_t short_length = s.size();
    const size_t long_length = t.size();
    bool can_match = false;

    if (short_length == long_length) {
        int mismatches = 0;
        for (size_t i = 0; i < short_length; ++i) {
            if (s[i] != t[i]) ++mismatches;
            if (mismatches == 2) break;
        }
        can_match = (mismatches <= 1);
    } else if (long_length - short_length == 1) {
        size_t prefix = 0;
        while (prefix < short_length && s[prefix] == t[prefix]) {
            ++prefix;
        }

        size_t suffix = 0;
        while (suffix < short_length &&
               s[short_length - 1 - suffix] == t[long_length - 1 - suffix]) {
            ++suffix;
        }

        can_match = (suffix >= short_length - prefix);
    }

    cout << (can_match ? "Yes" : "No") << '\n';
}
```

## 実装の要点

- 等長のときは不一致が0個なら編集なし、1個なら置換で一致する。2個目を見つけた時点で比較を打ち切れる。
- 長さ差1のときは、共通の接頭辞と接尾辞の最大長を `prefix`、`suffix` に持つ。長い方の位置 `i` を除けるなら、前から `i` 文字、後ろから `short_length-i` 文字が一致するため、両方の最大長の合計は `short_length` 以上になる。逆に、`suffix >= short_length - prefix` なら位置 `prefix` を除けば一致する。
- 長さ差が2以上の場合は `can_match` が初期値の `false` のままになる。

## 計算量・注意点

時間 O(|S| + |T|)、入力文字列を除く追加メモリ O(1)。末尾の比較はそれぞれの文字列の末尾から行い、短い方の長さで打ち切る。先頭・末尾の編集も含め、同じ文字が続くと前後の一致範囲は重なってよい。保存済みPython実装は挿入と削除を別々に分岐するが、この例では短い方と長い方の役割を揃えて同じ走査を使う。
