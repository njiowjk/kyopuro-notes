# 文字種ごとの対応表で一括置換を合成する

## やりたいこと

小さい固定文字集合の文字列で、現在の文字 `c` のすべてを `d` に変える操作を順に処理し、最後の文字列を得る。各位置に同じ置換規則が適用される。

## 基本的な考え方

元の文字種から現在の文字への対応表を作り、初期値を元の文字自身にする。置換のたびに表だけを書き換え、すべての操作を終えてから各位置に対応表を適用する。

## 実装（C++）

`abc342_c` の入力に対応する例。`N S Q` に続けて英小文字の組 `c d` を `Q` 組読む。原文字への添字付けと対応表を明示し、処理後に `S` をその場で書き換える。


```cpp
#include <algorithm>
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    string s;
    cin >> n >> s >> q;
    string image = "abcdefghijklmnopqrstuvwxyz";
    for (int i = 0; i < q; ++i) {
        char from, to;
        cin >> from >> to;
        replace(image.begin(), image.end(), from, to);
    }
    for (char& c : s) c = image[c - 'a'];
    cout << s << '\n';
}
```

## 実装の要点

表の `i` 番目は元の `i` 番目の文字種が現時点で何に変わったかを表す。次の置換は、表の値で `from` に一致する全要素に作用する。最終的な各位置の文字は元の文字を1回表で引けば得られる。

## 計算量・注意点

文字種数を `Σ` とすると時間 O(N+ΣQ)、入力を除く追加メモリ O(Σ)。英小文字は例の実行環境で連続する文字コードを使う。`from == to`、置換元が現在の文字列に存在しない場合、複数の元文字が同じ文字へ合流する場合もそのまま処理できる。
