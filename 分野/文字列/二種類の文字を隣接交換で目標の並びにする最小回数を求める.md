# 二種類の文字を隣接交換で目標の並びにする最小回数を求める

## やりたいこと

二種類の文字からなる文字列を、隣り合う文字の交換で目標の並びにする最小回数を求める。元の文字列と目標列では、各文字の個数がそれぞれ等しいとする。

## 基本的な考え方

片方の文字に注目し、元の列の `k` 番目の出現を目標列の `k` 番目の出現に対応させる。対応する添字の差の絶対値を足すと、隣接交換の最小回数になる。

## 実装（C++）

`abc421_c` の形式で `N` と `A`、`B` を `N` 個ずつ含む長さ `2N` の文字列を読み、交互列にする最小回数を出力する。照合済み実装は偶数位置に置く文字を変えて2回走査する。この例では `A` の出現を1回だけ走査し、二通りの目標への費用を同時に求める。

```cpp
#include <algorithm>
#include <cstdlib>
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    string s;
    cin >> n >> s;

    long long target = 0;
    long long starts_with_a = 0;
    long long starts_with_b = 0;
    for (int i = 0; i < 2 * n; ++i) {
        if (s[i] == 'A') {
            starts_with_a += abs(i - target);
            starts_with_b += abs(i - (target + 1));
            target += 2;
        }
    }
    cout << min(starts_with_a, starts_with_b) << '\n';
}
```

## 実装の要点

- 同じ文字同士の交換は省けるので、注目する文字の出現順は保たれる。異なる文字の交換1回で注目する文字が1つだけ1マス動くため、対応する目標位置までの距離の総和は交換回数の下限になる。
- 左から最初に食い違う位置に、右側で最も近い必要な文字を運ぶ。その間にある文字はすべてもう一方の種類で、隣接交換のたびに注目する文字が目標に1マス近づく。これを繰り返して距離の総和を0にできるため、下限に達する。
- `target` は `A` で始まる交互列で次の `A` が入る偶数位置。`B` で始まる場合の目標位置は `target + 1` になる。`A` に出会うごとに両方の費用を足して `target` を2進め、最後に小さい費用を選ぶ。

## 計算量・注意点

例では長さ `2N` の文字列を一度走査するので時間 O(N)、入力文字列を除く追加メモリ O(1)。すでに交互なら答えは0。片方の文字が固まっていると交換回数は二次の大きさになり得るため、費用の合計には `long long` を使う。

固定された任意の目標列にも、注目する文字の次の出現位置を順に取得すれば使える。三種類以上の文字がある場合は、追跡していない文字同士の交換も必要になり得る。
