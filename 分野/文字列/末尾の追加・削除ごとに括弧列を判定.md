# 末尾の追加・削除ごとに括弧列を判定

## やりたいこと

丸括弧1種類の列に末尾追加と末尾削除を行い、各操作直後に正しい括弧列か判定する。削除時には文字が1個以上ある。

## 基本的な考え方

長さごとに、左括弧を `+1`、右括弧を `-1` とした残高と、そこまでの接頭辞最小値を保存する。現在の長さの状態はスタックの末尾にあり、削除すると一つ短い長さの状態に戻る。

## 実装（C++）

`abc428_c` の入力に対応する例。`Q` に続けて `1 c`（追加）または `2`（削除）を読み、各操作後に `Yes` / `No` を出力する。2本の履歴を1個の `pair` にまとめる。


```cpp
#include <algorithm>
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int q;
    cin >> q;
    vector<pair<int, int>> states{{0, 0}};
    for (int i = 0; i < q; ++i) {
        int type;
        cin >> type;
        if (type == 1) {
            char c;
            cin >> c;
            const auto [balance, minimum] = states.back();
            const int next = balance + (c == '(' ? 1 : -1);
            states.emplace_back(next, min(minimum, next));
        } else {
            states.pop_back();
        }
        const auto [balance, minimum] = states.back();
        cout << (balance == 0 && minimum == 0 ? "Yes" : "No") << '\n';
    }
}
```

## 実装の要点

スタックの底に置いた初期状態 `(0, 0)` は空接頭辞に対応する。追加時は残高を ±1 し、新しい残高を接頭辞最小値に反映する。削除時はその長さの状態が1つ前にある。現在の残高が0で、すべての接頭辞が非負のときに全括弧を対応づけられる。

## 計算量・注意点

全体で償却 O(Q) 時間、最大の文字列長を `L` とすると追加メモリ O(L+1)。残高が0でも、`)(` のように途中で負になる列は無効。空文字列の状態を残す。
