# 10進数からk進数へ変換

k進数の文字列表現を作る。

```cpp
string to_base(ll n, int k) {
    if (n == 0) return "0";

    const string digits = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ";
    string res;

    while (n > 0) {
        res.push_back(digits[n % k]);
        n /= k;
    }

    reverse(res.begin(), res.end());
    return res;
}
```

`2 <= k <= 36` で使える。

k進数の文字列を数値へ戻す場合は、左から

`value = value * k + digit`

を繰り返す。
