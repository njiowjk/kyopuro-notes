# 固定3x3グリッド

3×3の行・列・斜めのように構造が固定なら、添字計算を頑張るより最初からlineを列挙すると実装が楽。

```cpp
vector<array<int, 3>> lines = {
    {0, 1, 2},
    {3, 4, 5},
    {6, 7, 8},
    {0, 3, 6},
    {1, 4, 7},
    {2, 5, 8},
    {0, 4, 8},
    {2, 4, 6},
};
```

各lineをそのまま回せる。

```cpp
for (const auto& line : lines) {
    for (int v : line) {
        // v はマス番号
    }
}
```

3要素固定なら `set` より `array<int, 3>` の方が単純でかなり軽い。

## 覚え方
固定で小さい構造 → 一般式より列挙を検討する。
