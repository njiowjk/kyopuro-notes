# 解法ノートの追加候補

[解法ノート一覧](解法ノート一覧.md) と既存ノートを確認し、用途をカバーできないときは下の書式で候補を1件ずつ追加する。利用者が保存先とテンプレート案を確認し、承認した候補を作成する。関連問題の整理前URLは [ローカル Inbox](Inbox仕様.md) に置く。

````markdown
## 候補名

- 状態　提案中 / 修正待ち / 承認済み
- 主分野・保存先　分野/<分野>/<ノート名>.md
- 概要と適用条件
- 既存ノートと比較した結果
- 関連問題　公開してよい task ID または作成済みの問題ノートへのリンク
- 承認記録　承認日と承認された保存先・案の要点

### C++ テンプレート案

```cpp
// 入出力・引数、再利用する処理、呼び出し例を記載する。
```

### 計算量・注意点

````

このファイルには反映が完了していない候補を置く。ノートの作成とリンクの検証を終え、[解法ノート一覧](解法ノート一覧.md) への登録と分野入口からの参照を確認したら、該当する候補セクションを削除する。見送りが確定した候補は取り下げる。[分類ルール](分類ルール.md)
