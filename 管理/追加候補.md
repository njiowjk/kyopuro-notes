## 末尾の追加・削除ごとに括弧列を判定

- 状態　提案中
- 主分野・保存先　分野/文字列/末尾の追加・削除ごとに括弧列を判定.md
- 概要と適用条件　丸括弧1種類の列に末尾追加と末尾削除を行い、各操作直後に正しい括弧列か判定する。削除時には文字が1個以上ある。
- 既存ノートと比較した結果　[STL / stack](../STL/queue-stack-deque-heap.md) の末尾操作と [累積和](../典型/累積和.md) の接頭辞の考え方を組み合わせ、各長さの残高と最小残高を一緒に保存する。削除後は1つ前の状態で即座に判定できる。
- 関連問題　[abc428_c](../問題/AtCoder/abc428_c.md)

### C++ テンプレート案

`Q` に続けて `1 c`（追加）または `2`（削除）を読み、各操作後に `Yes` / `No` を出力する。2本の履歴を1個の `pair` にまとめる。

```cpp
#include <algorithm>
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int q;
    cin >> q;
    vector<pair<int, int>> states{{0, 0}};
    for (int i = 0; i < q; ++i) {
        int type;
        cin >> type;
        if (type == 1) {
            char c;
            cin >> c;
            const auto [balance, minimum] = states.back();
            const int next = balance + (c == '(' ? 1 : -1);
            states.emplace_back(next, min(minimum, next));
        } else {
            states.pop_back();
        }
        const auto [balance, minimum] = states.back();
        cout << (balance == 0 && minimum == 0 ? "Yes" : "No") << '\n';
    }
}
```

### 実装の要点

スタックの底に置いた初期状態 `(0, 0)` は空接頭辞に対応する。追加時は残高を ±1 し、新しい残高を接頭辞最小値に反映する。削除時はその長さの状態が1つ前にある。現在の残高が0で、すべての接頭辞が非負のときに全括弧を対応づけられる。

### 計算量・注意点

全体で償却 O(Q) 時間、最大の文字列長を `L` とすると追加メモリ O(L+1)。残高が0でも、`)(` のように途中で負になる列は無効。空文字列の状態を残す。

## 逆引きと残数で必要条件がそろった対象を数える

- 状態　提案中
- 主分野・保存先　分野/グラフ/逆引きと残数で必要条件がそろった対象を数える.md
- 概要と適用条件　条件が一度ずつ成立し、成立後は取り消されないとき、全条件が成立した対象の数を各更新後に答える。条件と対象を二部グラフの頂点と見なし、条件側の隣接リストを作る。
- 既存ノートと比較した結果　[DFS](../アルゴリズム/DFS.md) の隣接リストは到達可能性の探索に使う。この案では条件から直接影響を受ける対象だけを逆引きし、対象ごとの未成立数を更新する。
- 関連問題　[abc402_c](../問題/AtCoder/abc402_c.md)

### C++ テンプレート案

`N M`、各対象の条件数と1始まりの条件番号、最後に `N` 個の成立順を読む。各対象内の条件番号は相異なり、成立順は `1..N` の順列。元の入力で重複がないため、逆引きは集合から `vector` に置き換える。条件数0の対象も初期状態で数えられる形にする。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    vector<vector<int>> dependents(n);
    vector<int> remaining(m);
    int ready = 0;
    for (int target = 0; target < m; ++target) {
        cin >> remaining[target];
        if (remaining[target] == 0) ++ready;
        for (int j = 0; j < remaining[target]; ++j) {
            int condition;
            cin >> condition;
            dependents[condition - 1].push_back(target);
        }
    }

    for (int day = 0; day < n; ++day) {
        int condition;
        cin >> condition;
        for (int target : dependents[condition - 1]) {
            if (--remaining[target] == 0) ++ready;
        }
        cout << ready << '\n';
    }
}
```

### 実装の要点

未成立の条件だけが `remaining` に残る。条件成立時にその逆引きリストを走査すれば、影響を受ける対象だけの残数を1減らせる。初期状態から残数0の対象と `1 → 0` に移った対象を1回ずつ数える。

### 計算量・注意点

条件と対象を結ぶ辺の総数を `E` とすると時間・追加メモリともに O(N+M+E)。同一条件の再通知を許す場合は通知済みを記録する。同じ条件が一対象内で重複する入力では、事前に重複を除く。

## 公差が同じ有限等差数列の共通最大値を求める

- 状態　提案中
- 主分野・保存先　分野/整数/公差が同じ有限等差数列の共通最大値を求める.md
- 概要と適用条件　正の共通公差 `d` を持つ有限等差数列が複数あるとき、すべてに含まれる最大値を求める。各列は両端も含み、途中に欠番がない。
- 既存ノートと比較した結果　[mod 計算](../数学/mod計算.md) は剰余の取り方を扱う。この案は各列の剰余と区間の両方を確認し、共通値と元の列での添字を求める用途を扱う。
- 関連問題　[abc432_c](../問題/AtCoder/abc432_c.md)

### C++ テンプレート案

`abc432_c` 形式で `N X Y` と `A_i` を読み、列の初項を `A_i*X`、末項を `A_i*Y`、公差を `Y-X` とする。共通最大値を求めた後、それぞれの列での0始まりの添字を大きい飴の数として合計する。

```cpp
#include <algorithm>
#include <iostream>
#include <limits>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    long long x, y;
    cin >> n >> x >> y;
    vector<long long> count(n);
    for (long long& a : count) cin >> a;

    const long long step = y - x;
    const long long residue = count.front() * x % step;
    long long low = 0;
    long long high = numeric_limits<long long>::max();
    for (long long a : count) {
        const long long first = a * x;
        if (first % step != residue) {
            cout << -1 << '\n';
            return 0;
        }
        low = max(low, first);
        high = min(high, a * y);
    }

    // high はいずれかの列の末項なので、剰余も一致する。
    if (low > high) {
        cout << -1 << '\n';
        return 0;
    }
    long long total = 0;
    for (long long a : count) total += (high - a * x) / step;
    cout << total << '\n';
}
```

### 実装の要点

各列の値は両端の閉区間にあり、初項と同じ剰余を持つ整数全体に等しい。剰余が一致すれば、共通区間の上端はどれかの末項なので剰余も一致する。したがって区間が空でなければ上端が答えになる。ローカル実装で行っていた剰余への切り下げは、この末項の性質によって省ける。

### 計算量・注意点

時間 O(N)、入力を除く追加メモリ O(1)。初項が負になり得る場合は剰余を `[0,d)` に正規化する。上端が実際の末項とは限らない追加制約を入れる場合は、剰余が一致する値まで上端を下げてから下端との大小を比較する。飴の入力では積は最大 `10^18`、個数の合計は最大 `2×10^14`。

## 外周につながらない連結成分を数える

- 状態　提案中
- 主分野・保存先　分野/グリッド/外周につながらない連結成分を数える.md
- 概要と適用条件　長方形グリッドで、通行可能なマスからなる4近傍連結成分のうち、外周のマスを含まないものを数える。
- 既存ノートと比較した結果　[BFS](../アルゴリズム/BFS.md) の多点探索と [DFS](../アルゴリズム/DFS.md) の成分数の数え方を使う。この案では外周を始点に除外する範囲を先に確定し、同じ訪問済み状態で内部だけを数える。
- 関連問題　[abc450_c](../問題/AtCoder/abc450_c.md)

### C++ テンプレート案

`H W` と `.`・`#` のグリッドを読み、囲まれた `.` の成分数を出力する。幅・高さは1以上とする。ローカル実装は訪問済み配列を持つが、この例では入力グリッドを変更できる前提で、キューへ入れたマスを `#` にする。外周の始点はまとめてキューに入れる。

```cpp
#include <iostream>
#include <queue>
#include <string>
#include <utility>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int h, w;
    cin >> h >> w;
    vector<string> grid(h);
    for (string& row : grid) cin >> row;

    queue<pair<int, int>> cells;
    const int dr[] = {-1, 1, 0, 0};
    const int dc[] = {0, 0, -1, 1};
    auto enqueue = [&](int row, int col) {
        if (grid[row][col] != '.') return;
        grid[row][col] = '#';
        cells.emplace(row, col);
    };
    auto flood = [&] {
        while (!cells.empty()) {
            const auto [row, col] = cells.front();
            cells.pop();
            for (int d = 0; d < 4; ++d) {
                const int r = row + dr[d];
                const int c = col + dc[d];
                if (0 <= r && r < h && 0 <= c && c < w) enqueue(r, c);
            }
        }
    };

    for (int row = 0; row < h; ++row) {
        enqueue(row, 0);
        enqueue(row, w - 1);
    }
    for (int col = 0; col < w; ++col) {
        enqueue(0, col);
        enqueue(h - 1, col);
    }
    flood();

    int enclosed = 0;
    for (int row = 1; row + 1 < h; ++row) {
        for (int col = 1; col + 1 < w; ++col) {
            if (grid[row][col] != '.') continue;
            ++enclosed;
            enqueue(row, col);
            flood();
        }
    }
    cout << enclosed << '\n';
}
```

### 実装の要点

外周の通行可能マスから到達できるマスは、外周に触れる成分の和集合と一致する。残った `.` を見つけるたびに成分全体を消すと、同じ成分を再び数えずに済む。

### 計算量・注意点

時間 O(HW)、キューの追加メモリは最悪 O(HW)。キューへの追加時に訪問済みにするので、角を複数回調べても追加は1回。盤面を維持するなら別に訪問済み配列を使う。斜めの接触も連結とする場合は、両段階の近傍を8方向にそろえる。

## 文字種ごとの対応表で一括置換を合成する

- 状態　提案中
- 主分野・保存先　分野/文字列/文字種ごとの対応表で一括置換を合成する.md
- 概要と適用条件　小さい固定文字集合の文字列で、現在の文字 `c` のすべてを `d` に変える操作を順に処理し、最後の文字列を得る。各位置に同じ置換規則が適用される。
- 既存ノートと比較した結果　[STL / string](../STL/string.md) は文字列操作を扱う。[1文字更新後の固定パターン出現数を差分更新](../分野/文字列/1文字更新後の固定パターン出現数を差分更新.md) は位置指定の置換を扱う。この案は元の文字種を添字にして置換規則を合成し、入力文字列への適用を最後にまとめる。
- 関連問題　[abc342_c](../問題/AtCoder/abc342_c.md)

### C++ テンプレート案

`N S Q` に続けて英小文字の組 `c d` を `Q` 組読む。原文字への添字付けと対応表を明示し、処理後に `S` をその場で書き換える。

```cpp
#include <algorithm>
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    string s;
    cin >> n >> s >> q;
    string image = "abcdefghijklmnopqrstuvwxyz";
    for (int i = 0; i < q; ++i) {
        char from, to;
        cin >> from >> to;
        replace(image.begin(), image.end(), from, to);
    }
    for (char& c : s) c = image[c - 'a'];
    cout << s << '\n';
}
```

### 実装の要点

表の `i` 番目は元の `i` 番目の文字種が現時点で何に変わったかを表す。次の置換は、表の値で `from` に一致する全要素に作用する。最終的な各位置の文字は元の文字を1回表で引けば得られる。

### 計算量・注意点

文字種数を `Σ` とすると時間 O(N+ΣQ)、入力を除く追加メモリ O(Σ)。英小文字は例の実行環境で連続する文字コードを使う。`from == to`、置換元が現在の文字列に存在しない場合、複数の元文字が同じ文字へ合流する場合もそのまま処理できる。

## 閉区間に含まれる等差数列の項数を数える

- 状態　提案中
- 主分野・保存先　分野/整数/閉区間に含まれる等差数列の項数を数える.md
- 概要と適用条件　任意の整数 `k` に対する `a+k*m` のうち、閉区間 `[l,r]` に含まれる項の個数を求める。`m>0`、`l<=r` とし、座標と `k` は負でもよい。
- 既存ノートと比較した結果　[mod 計算](../数学/mod計算.md) には剰余の符号の補正がある。この案は剰余の符号から整数商の丸めを補正して、閉区間を添字の範囲に変換する。
- 関連問題　[abc334_b](../問題/AtCoder/abc334_b.md)

### C++ テンプレート案

`a m l r` を読み、個数を出力する。ローカル実装の床・天井の分岐を、符号付き商に剰余の符号を反映する形にまとめる。

```cpp
#include <iostream>
using namespace std;

int main() {
    long long a, m, l, r;
    cin >> a >> m >> l >> r;

    const long long left = l - a;
    const long long right = r - a;
    const long long first = left / m + (left % m > 0);
    const long long last = right / m - (right % m < 0);
    cout << last - first + 1 << '\n';
}
```

### 実装の要点

許される添字は `ceil((l-a)/m)` 以上、`floor((r-a)/m)` 以下。C++ の整数除算は0方向に丸めるので、正の剰余なら天井を1増やし、負の剰余なら床を1減らす。`l<=r` なら、有効な添字がない場合は `first == last+1` になる。

### 計算量・注意点

時間・追加メモリともに O(1)。両端を含むので個数は `last-first+1`。剰余が0なら商を変えない。例は座標差・添字差・個数が符号付き64ビット整数に収まる範囲で使う。
