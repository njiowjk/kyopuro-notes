## 1回以内の文字編集で一致するか判定

- 状態　提案中
- 主分野・保存先　`分野/文字列/1回以内の文字編集で一致するか判定.md`
- 概要と適用条件　1文字の挿入・削除・置換を合わせて高々1回行い、2つの文字列を一致させられるか判定する。各文字を定数時間で比較できる列を扱う。

まず短い方を `s` に揃える。等長なら不一致数を数え、長さが1違うなら前後の一致長で短い方を覆えるか調べる。

### C++ テンプレート案

入力は `1`、文字列 `s`、`t` の3行。文字列の行が空でも扱える。

```cpp
#include <iostream>
#include <limits>
#include <string>
#include <utility>
using namespace std;

int main() {
    int k;
    string s, t;
    cin >> k;  // この例では k = 1
    cin.ignore(numeric_limits<streamsize>::max(), '\n');
    getline(cin, s);
    getline(cin, t);

    if (s.size() > t.size()) swap(s, t);
    const size_t short_length = s.size();
    const size_t long_length = t.size();
    bool can_match = false;

    if (short_length == long_length) {
        int mismatches = 0;
        for (size_t i = 0; i < short_length; ++i) {
            if (s[i] != t[i]) ++mismatches;
            if (mismatches == 2) break;
        }
        can_match = (mismatches <= 1);
    } else if (long_length - short_length == 1) {
        size_t prefix = 0;
        while (prefix < short_length && s[prefix] == t[prefix]) {
            ++prefix;
        }

        size_t suffix = 0;
        while (suffix < short_length &&
               s[short_length - 1 - suffix] == t[long_length - 1 - suffix]) {
            ++suffix;
        }

        can_match = (suffix >= short_length - prefix);
    }

    cout << (can_match ? "Yes" : "No") << '\n';
}
```

### 実装の要点

等長なら操作0回または1回の置換で一致する条件は、不一致が1か所以下であること。長さ差1で長い方の位置 `i` を除くには、その前の `i` 文字とその後の `short_length-i` 文字が一致する必要がある。削除できる位置があれば、前後の一致長の合計は短い方の長さ以上になる。逆に、`prefix` 文字を前から使って残りを `suffix` で覆えれば、長い方の位置 `prefix` を除いて一致させられる。長さ差が2以上なら1回では揃わない。

### 計算量・注意点

時間 O(|S| + |T|)、入力文字列を除く追加メモリ O(1)。前後の走査は短い方の長さまで。先頭・末尾の編集や同じ文字が連続する場合も扱える。前後の一致範囲が重なってもよい。

- 関連問題　[abc386_c](../問題/AtCoder/abc386_c.md)
- 既存ノートと比較した結果　[STL / string](../STL/string.md) は文字列の基本操作、[LCS](../アルゴリズム/LCS.md) は共通部分列の長さを扱う。この候補からは1回以内の編集判定に使う長さの分岐と比較範囲を参照できる。

## 1文字更新後の固定パターン出現数を差分更新

- 状態　提案中
- 主分野・保存先　`分野/文字列/1文字更新後の固定パターン出現数を差分更新.md`
- 概要と適用条件　文字列 `s` の1文字置換を繰り返すとき、固定した空でない短いパターンの出現数を求める。重なる出現も開始位置ごとに数える。

現在の文字列と出現数 `occurrences` を持つ。置換位置を含む窓について、変更前の一致を引き、置換してから変更後の一致を足す。

### C++ テンプレート案

入力は `n q`、長さ `n` の文字列、続けて `q` 行の `pos replacement`。文字列は空白を含まない長さ1以上の文字列とし、位置は1〜`n`。文字列・パターンの長さは `int` に収まる。別の固定パターンには `pattern` を差し替える。

```cpp
#include <algorithm>
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    string s;
    cin >> n >> q >> s;
    const string pattern = "ABC";
    const int length = static_cast<int>(pattern.size());
    const int last_start = n - length;

    int occurrences = 0;
    for (int start = 0; start <= last_start; ++start) {
        if (s.compare(start, length, pattern) == 0) ++occurrences;
    }

    for (int query = 0; query < q; ++query) {
        int pos;
        char replacement;
        cin >> pos >> replacement;
        --pos;

        if (s[pos] == replacement) {
            cout << occurrences << '\n';
            continue;
        }

        const int first = max(0, pos - length + 1);
        const int last = min(pos, last_start);
        for (int start = first; start <= last; ++start) {
            if (s.compare(start, length, pattern) == 0) --occurrences;
        }

        s[pos] = replacement;

        for (int start = first; start <= last; ++start) {
            if (s.compare(start, length, pattern) == 0) ++occurrences;
        }
        cout << occurrences << '\n';
    }
}
```

### 実装の要点

長さ `L` の窓が `pos` を含むのは、開始位置が `[pos-L+1, pos]` にある場合だけ。有効な開始位置 `[0, n-L]` との共通部分を `[first, last]` として両端を含めて走査する。この範囲外の一致は変わらないため、前後の差だけで全体の出現数を更新できる。

### 計算量・注意点

有効な窓数を `W = max(0, n-L+1)` とすると、初回の比較は O(WL)、1更新は最悪 O(1 + min(L,W)×L)。`L` が定数なら入力を含めて O(n + q)、保持する文字列は O(n + L)、走査用の追加メモリは O(1)。`n < L` では窓がなく、出現数は常に0。

- 関連問題　[abc372_c](../問題/AtCoder/abc372_c.md)
- 既存ノートと比較した結果　[STL / string](../STL/string.md) の文字列操作を使い、置換で影響を受ける範囲と出現数の更新順をまとめる。

## 部分列に含まれるかを貪欲に判定

- 状態　提案中
- 主分野・保存先　`分野/文字列/部分列に含まれるかを貪欲に判定.md`
- 概要と適用条件　文字列 `target` が `s` の部分列として存在するか判定する。文字は離れていてもよく、選ぶ位置は左から順に進める。

`matched` に確定済みの文字数を持つ。`s` を左から読み、`target[matched]` と一致したらその位置を使う。

### C++ テンプレート案

入力は `s` と `target` の2行。下の例は `abc349_c` の空港コード用に `s` の大文字化と末尾への `X` の追加を行う。入力をそのまま部分列判定する場合は、その2処理を省いて使う。

```cpp
#include <cctype>
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s, target;
    getline(cin, s);
    getline(cin, target);

    // abc349_c 固有の前処理
    for (char& c : s) c = static_cast<char>(toupper(static_cast<unsigned char>(c)));
    s.push_back('X');

    size_t matched = 0;
    for (char c : s) {
        if (matched == target.size()) break;
        if (c == target[matched]) ++matched;
    }

    cout << (matched == target.size() ? "Yes" : "No") << '\n';
}
```

### 実装の要点

`k` 文字目を最初に一致する位置で選べば、その後ろに残る範囲は他の選び方より狭くならない。各文字について同じ選び方ができるため、最後まで一致すれば部分列が存在する。空の `target` は最初から一致済み。同じ文字が続く場合もループ1回で使える位置は1つだけ。

### 計算量・注意点

判定ループは時間 O(|S| + 1)、追加メモリ O(1)。入力の読み込みは O(|S| + |T|)。`abc349_c` で末尾に足した `X` を使えるのは `target` の最後の1文字だけ。

- 関連問題　[abc349_c](../問題/AtCoder/abc349_c.md)
- 既存ノートと比較した結果　[STL / string](../STL/string.md) に文字の大文字化、[LCS](../アルゴリズム/LCS.md) に共通部分列の長さを求める方法がある。この候補は指定済みの部分列が存在するかの判定に使う。

## ソート済み配列で条件を満たすペアを数える

- 状態　提案中
- 主分野・保存先　`分野/配列/ソート済み配列で条件を満たすペアを数える.md`
- 概要と適用条件　昇順配列 `a` から、`i < j` かつ `a[j] >= threshold` となる添字ペアを数える。閾値は左側の添字 `i` ごとに決まる。順序を変えても答えが同じ場合は先に整列できる。

`i` を固定すると、有効な `j` は `[i+1, n)` の途中から末尾まで続く。閾値以上になる最初の位置を求め、そこから末尾までの個数を足す。

### C++ テンプレート案

#### 二分探索で毎回境界を求める

閾値が下がる場合も使える。`abc353_c` 形式で `n` と `n` 個の整数を読み、整列して `mod-a[i]` 以上の相手を数える。この例の剰余の集計は `0 <= a[i] < mod` で使える。

```cpp
#include <algorithm>
#include <iostream>
#include <numeric>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<long long> a(n);
    for (long long& x : a) cin >> x;
    sort(a.begin(), a.end());

    constexpr long long mod = 100000000;
    long long wrapped_pairs = 0;
    for (int i = 0; i < n; ++i) {
        const long long threshold = mod - a[i];
        const auto first = lower_bound(a.begin() + i + 1, a.end(), threshold);
        wrapped_pairs += a.end() - first;
    }

    const long long sum = accumulate(a.begin(), a.end(), 0LL);
    cout << (n - 1LL) * sum - mod * wrapped_pairs << '\n';
}
```

#### 閾値が非減少なら尺取りで境界を進める

`abc388_c` の入力は `n` と昇順の正整数列 `a`。閾値 `2*a[left]` は `left` を進めても下がらない。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<long long> a(n);
    for (long long& x : a) cin >> x;

    long long pairs = 0;
    int right = 0;
    for (int left = 0; left + 1 < n; ++left) {
        const long long threshold = 2LL * a[left];
        right = max(right, left + 1);
        while (right < n && a[right] < threshold) ++right;
        if (right == n) break;
        pairs += n - right;
    }

    cout << pairs << '\n';
}
```

### 実装の要点

- 探索を `i+1` から始めれば、自己ペアと逆順の二重計上を防げる。同じ値でも添字が違えば別のペアになる。境界を `r` とすると、条件を満たすのは `[r,n)` の `n-r` 個。
- `mod-a[i]` は整列後に非増加なので、前回の境界より左に有効な相手が現れ得る。二分探索は毎回 `[i+1,n)` を調べる。`abc353_c` では各要素が剰余を取る前の総和に `n-1` 回現れる。各ペアの和は `2*mod` 未満なので、和が `mod` 以上のペアごとに `mod` を1回引けばよい。
- 尺取りでは閾値と探索の左端がともに非減少なので、前回の `right` より左に戻る必要がない。`right == n` なら後の閾値でも有効な相手は見つからない。

### 計算量・注意点

二分探索版は整列込みで O(n log n)、尺取り版は `right` が合計で最大 `n` 回進むので整列済みなら O(n)。配列と整列の作業領域を除き、計数の追加メモリは O(1)。等号を含むので `lower_bound` または `a[right] < threshold` を使う。倍・差・積とペア総数は `long long` に収まる範囲で使う。

- 関連問題　[abc388_c](../問題/AtCoder/abc388_c.md)、[abc353_c](../問題/AtCoder/abc353_c.md)
- 既存ノートと比較した結果　[STL / sort・search](../STL/sort-search.md) の境界探索と [尺取り法](../アルゴリズム/尺取り法.md) の単調性を、添字ペアの計数に使う。剰余の扱いは [mod計算](../数学/mod計算.md) も参照できる。
- 承認記録　未承認

## 追加・削除される多重集合の種類数を管理

- 状態　提案中
- 主分野・保存先　`分野/配列/追加・削除される多重集合の種類数を管理.md`
- 概要と適用条件　同じ値を複数個持てる集合に1個ずつ追加・削除し、現在の種類数を答える。削除する値はその時点で存在する。

値ごとの頻度を `freq` に持ち、頻度が正の値の数を `distinct` として管理する。

### C++ テンプレート案

最初にクエリ数 `q` を読み、続けて `1 x` は追加、`2 x` は削除、`3` は種類数の出力として処理する。

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int q;
    cin >> q;
    unordered_map<long long, int> freq;
    int distinct = 0;

    for (int query = 0; query < q; ++query) {
        int type;
        cin >> type;
        if (type == 3) {
            cout << distinct << '\n';
            continue;
        }

        long long x;
        cin >> x;
        int& count = freq[x];

        if (type == 1) {
            ++count;
            if (count == 1) ++distinct;
        } else {
            --count;
            if (count == 0) --distinct;
        }
    }
}
```

### 実装の要点

1回の操作で変わるのは値 `x` の頻度だけ。`0 → 1` で新しい種類が増え、`1 → 0` で最後の1個が消える。初期状態は空なので、この2つの遷移を処理すれば `distinct` は常に現在の種類数になる。

### 計算量・注意点

追加・削除は期待償却 O(1)、種類数の照会は O(1)、全体の期待時間 O(q)。頻度0でもキーを残すため、メモリはこれまでに追加した異なる値の数 `U` に対して O(U)。0になったキーを消す方式なら `freq.size()` が種類数になる。存在しない値の削除も入力される場合は、`find` でキーがあり頻度が正であることを確認してから減らす。

- 関連問題　[abc366_c](../問題/AtCoder/abc366_c.md)
- 既存ノートと比較した結果　[STL / set・map](../STL/set-map.md) の頻度表と [文字カウント](../典型/文字カウント.md) の集計を、追加・削除と種類数の維持に使う。

## 行・列・対角線の完成をカウンタで検出

- 状態　提案中
- 主分野・保存先　`分野/グリッド/行・列・対角線の完成をカウンタで検出.md`
- 概要と適用条件　正方形の盤面で相異なるマスを順に印付けし、行・列・2本の対角線のどれかが初めて埋まる手番を求める。マス番号は1始まりの行優先順。

線ごとに印の数を持ち、今のマスが属する線だけ更新する。

### C++ テンプレート案

入力は一辺の長さ `n`、手数 `t`、続けて1〜`n²` の相異なる `t` 個のマス番号。`n >= 1` とし、`n²` と手数は `int` に収まる。完成した手番を1始まりで、未達成なら `-1` を出力する。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, t;
    cin >> n >> t;
    vector<int> row_count(n), col_count(n);
    int main_diag = 0, anti_diag = 0;

    for (int turn = 0; turn < t; ++turn) {
        int cell;
        cin >> cell;
        --cell;

        const int row = cell / n;
        const int col = cell % n;
        ++row_count[row];
        ++col_count[col];
        if (row == col) ++main_diag;
        if (row + col == n - 1) ++anti_diag;

        if (row_count[row] == n || col_count[col] == n ||
            main_diag == n || anti_diag == n) {
            cout << turn + 1 << '\n';
            return 0;
        }
    }

    cout << -1 << '\n';
}
```

### 実装の要点

番号を0始まりに直すと、商が行、余りが列になる。1手で増えるのは対応する行と列、および条件を満たす対角線だけ。重複のない宣言ではカウンタは各線に印が付いたマスの数と一致する。初めてどれかが `n` に達した時点が答えになる。

### 計算量・注意点

時間 O(n + t)、メモリ O(n)。奇数サイズの中心は両方の対角線に属するので、2つの `if` を独立させる。重複する番号を許す場合は、同じマスの印を再加算せず、手番は元の宣言順で数える。

- 関連問題　[abc355_c](../問題/AtCoder/abc355_c.md)
- 既存ノートと比較した結果　[固定3x3グリッド](../典型/固定3x3グリッド.md) は固定の線を列挙する。この候補は一辺の長さが変わる盤面で、更新のたびに座標から該当する線を特定する。

## 無向グラフから自己ループと多重辺を除く

- 状態　提案中
- 主分野・保存先　`分野/グラフ/無向グラフから自己ループと多重辺を除く.md`
- 概要と適用条件　無向グラフの頂点をすべて残し、単純グラフにするための最小削除辺数を求める。自己ループと、端点の順序が逆になった同じ辺も入力され得る。

自己ループは到着時に削除する。他の辺は端点を小さい順に並べ、同じ端点対の初出だけを `set` に残す。

### C++ テンプレート案

入力は頂点数 `n` と辺数 `m`、続けて `m` 行の端点 `u v`。端点は1〜`n`。

```cpp
#include <iostream>
#include <set>
#include <utility>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    set<pair<int, int>> seen;
    int removed = 0;

    for (int edge = 0; edge < m; ++edge) {
        int u, v;
        cin >> u >> v;
        if (u == v) {
            ++removed;
            continue;
        }

        if (u > v) swap(u, v);
        const bool inserted = seen.emplace(u, v).second;
        if (!inserted) ++removed;
    }

    cout << removed << '\n';
}
```

### 実装の要点

自己ループは1本も残せない。非ループの辺は、同じ端点対が `k` 本あれば最大1本を残せる。`seen.emplace(u, v).second` が真ならその組の初出で、偽なら既に1本ある。初出だけを残せば各端点対で必要な `k-1` 本だけを削除できる。

### 計算量・注意点

異なる非ループ辺の数を `U` とすると時間 O(m log(U + 2))、追加メモリ O(U)。辺が0本なら答えは0。方向のある辺では端点を入れ替えず、`(u,v)` と `(v,u)` を区別する。
